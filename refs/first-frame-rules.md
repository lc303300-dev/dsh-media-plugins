# Seedance/Dreamina 首帧与参考条件化规则（DSH 版）

> 依据 third_party/seedance-2.0-prompt-skill（BytePlus ModelArk 官方 sd2-pe 的冲突消解改编）。
> 用于编写/修订参考型视频提示词时的首帧与绑定规则；平台标签语法仍以当前适配器为准。

## 首帧原则

1. **首帧即定帧**：图生视频（image-to-video）时，参考图片就是精确的**开场帧**。提示词只描述从该帧开始的**运动与变化**，不要重复描述帧内已存在的静态内容，更不要要求"首帧之后换成另一个场景"。
2. **首尾帧**：恰好两张图且用户明确首尾帧语义时走 frames2video：图1 是严格起始帧、图2 是严格结束帧，中间运动必须在这两个状态之间推进；不混用 API 角色。
3. **运动要服务于变化**：写"她转头看向镜头，嘴角缓缓上扬"，不写"她的表情很自然"。

## 参考条件化（绑定规则）

- 参考素材是"条件"，提示词是"计划"：把素材当成演员/场景/动作参考，为每份素材写明**单一职责**（identity 锁主体、style 锁风格、motion 锁运镜、audio 锁节奏）。
- 精确性优先：identity/product 锁定、精确编辑、逐字台词、编排（choreography）、UI/文字、首帧/尾帧要用确定性表述，留给模型的自由解释越少越好。
- 用中文裸标签引用（图片1、视频1、音频1），序号与 CLI 参数顺序严格一致；禁用 @图片1 形式的 mention-chip。

## 交付前清理

- 交付的提示词**不包含**模型名、分辨率、seed、参考模式、API 参数或供应商标签——这些走结构化参数，不写进提示词正文。
- 不确定的修正保持原样；只对不完整或结构性弱的提示词做优化。
