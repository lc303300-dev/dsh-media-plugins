## 一、导演创作工作流（video-director-prompt 移植）

1. 提取剧情转折、动作因果、情绪落点和结尾画面。
2. 建立连续性锚点：角色、服装、道具、空间、时间、天气、运动方向和状态变化。
3. 补齐首帧的主体位置、朝向、视线、前中后景、相机位置与主光方向。
4. 按**模板集**选模板：有分镜 → T1 `镜头N` 编号式或 T2 时间轴式；单镜头 → T3 内部时间轴或 T4 一镜到底式；
   有参考视频 → T5 视频驱动。**同一层只用一种分段手段。**
5. 分开编写主体运动与相机运动；每次运镜都要服务于信息、情绪或转场。
6. 把抽象情绪翻译成眼神、呼吸、肌肉、停顿、手部动作和空间关系。
7. 加入必要的质量约束与连续性锁定，避免堆叠无关术语。
8. 输出中文提示词；首次出现专业术语时采用 `English term（中文释义）`，后续用更简洁的一种写法。

## 二、证据分级（引用语料时的可信度）

- **通用原则**：来自电影语言、视觉叙事或跨模型稳定实践，可默认采用。
- **社区经验**：创作者反复使用的启发式方法，按镜头需要选用并接受模型差异。
- **实验性启发**：适合小范围试验的精细协议或数值锚点，不能保证复现。
- **平台约束**：标签、参数、素材上限等仅由当前生成平台的适配器决定，不写成通用技能规则。
- **官方范本**：最高等级，见正本第六节的填好示例；与社区经验冲突时以官方范本为准。

## 三、语料检索规则（prompt_revision search_corpus）

- 仅模糊/创意/结构修订可检索，最多 **10 条**；明确局部修改（explicit_local）禁止检索。
- 检索只提取可迁移的镜头结构或导演方法（portable_pattern），**不复制案例提示词**。
- 语料 `refs/forge-index.jsonl` 中大量条目用 `[00:00-00:05] 镜头1：` + `【风格】【时长】【场景】【角色】`
  形态——**这些形态与官方范例一致，是合法写法**，不要当成"过时写法"。检索时仍只提取**可迁移结构**
  （镜头推进、景别变化、物理反馈、连续性锁定），不要成段复制案例原文；按模板集选定模板组织后写入。
- 不把语料条目的模型版本、路径、示例作为选择生成模型的依据。

## 四、结构速查（模板选择与完整骨架见正本）

| 情况 | 模板 |
|---|---|
| 有分镜，逐镜推进 | T1 `镜头N` 编号式 |
| 有分镜，要精确控制每段时长/节奏 | T2 时间轴式（`0-1.5秒:` / `[00.0-03.0秒｜场景名]` + 区块头） |
| 单镜头，镜头内有连续变化（延时/渐变/变形） | T3 单一镜头 · 内部时间轴 |
| 单镜头，运动不中断，不要时间轴 | T4 单镜头连续（一镜到底式） |
| 有参考视频，迁移它的运镜/动作 | T5 视频驱动 |

**T1 骨架**：

```
镜头1：<景别·机位>，<主体·动作>，<素材绑定 图片N>，<材质·细节>，<一个主导运镜>
镜头2：……
镜头1-2：……            ← 相邻两镜可合并成一段
[段级质感句，可选，放最后]
```

整段应覆盖主体动作、素材绑定、景别、运镜（**个别镜可省略**，素材可沿用上一镜）；**次序灵活**（范例里动作常先于景别）；
排斥项与局部约束**内联句内**；段级质感句只在末尾写一次。**时间码与秒数区间标题是合法写法**，只有管道符拼接形态被拒。

### 常用运镜与术语

- 缓慢推进（push in）、后拉（pull back）、横移（truck）、环绕（orbit）、俯冲（dolly down）、手持微晃（handheld）、甩镜（whip pan）、跟拍（tracking）、固定机位（locked-off）、视场角（FOV）、场面调度（blocking）
- 术语只用于**描述画面**，不作分镜骨架；分段手段只有 `镜头N`（含 `镜头1-2` 合并段）。
- 一个镜头只给一个主导运镜，最多一个辅助动作；5 秒内动作不超过两个关键节拍。
- 光线给出光质与色温（柔光/硬光、暖调/冷调、逆光轮廓、体积光）；色彩倾向一句话（青橙色调，阴影偏青，高光偏暖）。
- 音频参考写明情绪、节奏与卡点；无音频时给出情绪基调词（克制、梦幻、紧张、静谧），并按默认追加 `不生成音乐，仅生成音效。`

## 五、场面/镜头/表演/光色/声音速查

- **场面**：时间、天气、环境氛围一句话；明确景别（远景/全景/中景/近景/特写）与主体位置。
- **表演**：动作具体可执行（不写"很自然"，写"她微微侧头看向镜头，嘴角缓缓上扬"）；节奏与镜头时长匹配。
- **光色**：光质+色温；色彩倾向一句话。
- **声音**：音频参考写明情绪/节奏/卡点；无音频时给情绪基调词。
- **标签**：中文裸标签 `图片N`，按 **图片 → 视频 → 音频 的传入顺序**重编号；禁 `@图片1`、
  禁 `参考图片N`；官方范本的原始编号与版本括号（`图片31(2)`）不得直接进提交文本——见正本第四节。
