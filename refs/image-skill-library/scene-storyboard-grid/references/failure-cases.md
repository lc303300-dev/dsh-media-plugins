# 失败案例与停止条件

每项按“症状 → 原因 → 修复 → 停止条件”检查。

1. 复制设定图黑色背景或排版 → 未限定设定图角色 → 明确背景、留白、注释和展示方式无效 → 无法区分主体与背景时停止。
2. 多视图变成多个主体 → 把视图当对象 → 写明所有视图是同一唯一主体 → 设定图包含多个不同主体且身份不明时停止。
3. 文字乱码、错序或镜像 → 未逐字符锁定 → 明确 exact character shapes and order, never mirror → 关键文字不可辨时停止。
4. 厚度、倒角、孔洞、比例或材质跨格漂移 → 身份连续性不足 → 把这些属性列为全局不变量 → 参考之间根本矛盾且无法裁决时停止。
5. 主体穿过楼、路或桥 → 未锁定空间几何 → 强调 installation point、contact geometry 与已有结构不可穿透 → 底图空间关系无法辨识时停止。
6. 前景遮挡丢失 → 未描述层级 → 指定哪些已有结构必须位于主体前方 → 遮挡关系不可确认时使用保守机位。
7. 投影、光向或接触矛盾 → 各格重建光照 → 锁定光向、影长、软硬度和接触 → 光源不可判断时避免强调投影镜头。
8. 新增建筑、人物、车辆、树、支架、平台或装饰 → 追求丰富画面 → 使用 closed-world 禁止新增或补全 → 用户要求新增内容时说明超出当前 Skill。
9. 九格都是相似正面图 → 镜头覆盖不足 → 在有证据的范围内组合整体、尺度、侧面、材质、遮挡和高低机位 → 可见半空间太窄时允许保守差异，不虚构背面。
10. 九个独立世界 → 每格独立生成描述 → 明确 same scene, same moment, one continuous physical world → 用户要求九种场景时转其他 Skill。
11. 出现时间推进或动作变化 → 误解 storyboard → 明确 simultaneous multi-camera observations, no temporal progression → 用户目标是事件进程时停止路由。
12. 标题、编号、水印或外框 → 把分镜当展示板 → 禁止任何额外文字、UI 与装饰边框。
13. 不是单张严格 3×3 或面板数错误 → 输出合同不清 → 写明 one complete image, exactly nine equal panels in a strict 3×3 grid。
14. 补全不可见背面或隐藏结构 → 大幅绕后机位超出证据 → 限制在可见半空间，改用裁切、焦段、景深和焦点变化 → 用户坚持未知背面时索要确定性补充素材；当前契约不接受临时第三槽。
15. 内部小图横竖方向与底图相反或九格混排 → 把外层输出比例误当成面板比例 → 从 `scene-base` 宽高关系锁定统一的 portrait、landscape 或 square 面板方向 → 底图方向因文件损坏或方向元数据无法判定时先完成方向规范化再继续。
16. 每张底图都机械出现孔洞窥视、投影、风化金属或暖色轮廓光 → 复制完整镜头池而未建立事实账本 → 为每个镜头记录直接证据，只写入 `supported` 项；证据不足时改用保守摄影机差异 → 若用户把无依据镜头设为硬要求，停止并说明需要确定性素材或转入其他工作流。

## 强停止条件

- 缺少 `scene-base`，或只有 `identity-design`。
- 引用超过两张、出现未声明槽、角色或顺序无法确定。
- 未明确选择支持的画幅比例。
- 主体类型或关键字符冲突，无法按权威规则裁决。
- 要求镜头依赖不可见几何、要求第三参考图，或要求取消单张 3×3 九格输出。
- 无法确定规范化后 `scene-base` 的横、竖或方形方向。

生成后的普通美术失败不得自动重试；修改提示词并重新确认，或由 Router 建立新批次身份。
