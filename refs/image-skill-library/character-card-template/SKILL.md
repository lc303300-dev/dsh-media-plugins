# 标准角色卡模板

## 核心任务

用户提供一张或多张人物照片，输出一张**版式固定**的标准角色卡：上排四格（正面全身 / 右侧面全身 / 背面全身 / 正面上半身近景），下排三格头肩特写（正脸 / 四分之三 / 正侧）。版式与取景是模板资产，人物身份、发型、服装、配饰全部来自照片。

## 版式硬规则（每次都要遵守）

1. 竖版 3:4，纯白无缝背景，无边框、无文字、无水印。
2. **版面高度分配**：上排图形占画面高约 52%（底边落在约 59% 处），排间空隙只留约 6%，下排头肩占约 34% 到底。排间空隙超过 10% 就会出现"上下断开"的空洞感，必须在提示词里单独写一句限制它。
3. 上排四格**底边齐平**（前三格脚底即底边，第 4 格腰线即底边），但四格**不等宽**：正面约 19.5%、侧面约 12%、背面约 19.5%、第 4 格约 33%（≈正面格的 1.6–1.7 倍）。第 4 格必须给更宽的格子，否则放大后手臂会被切。
4. 第 4 格是**正面**胸像，不是四分之三：头正、颈垂直、双肩水平、双耳对称；裁在**腰线**（上衣下摆与裤腰之间）；头部宽约第 1 格的 1.5–1.6 倍；头顶因此比前三格低约 5%；双臂垂直贴身、不被左右边缘切断。
5. 下排三张头部**同大、同顶线**，各占约 1/3 画面宽、头部高约 34% 画面高，统一裁到锁骨下缘；四分之三与正侧两张朝同一边。
6. 人物统一自然站立 A-pose（双臂外展 35–40°、双腿与肩同宽），四格与近景姿态一致；平视、正交感视角，无广角畸变。
7. 卡面人物必须就是照片本人：脸型、五官、发型走势、肤色、体型、服装款式与材质、配饰全部沿用，不美化、不换装、不添加照片里没有的元素。

完整比例表与自检清单见 `references/layout-spec.md`；提示词组织方式见 `references/examples.md`；常见翻车点见 `references/failure-cases.md`。

## 执行顺序

1. **brief**：确认画幅比例（缺省建议 3:4）、照片里的人物与外观清单、候选数量；缺少可用的正面或侧面照片时先说明只能推断哪部分。
2. **提示词 V1**：按 `references/examples.md` 的组织方式写出完整提示词，逐条覆盖版式六条硬规则 + 人物外观描述，展示给用户确认后再生产。
3. **生产**：单候选走 `image.generate`；多场景或多候选经付费批次确认后走 `image.batch-generate`，由平台层调度。
4. **final**：先用量测脚本核对版式（`assets/measure.py`），排间空隙超过画面高 8% 就用 `assets/relayout.py` 做确定性校正（删空白、重排到 3:4，不缩放不裁切内容），复验通过再交付；人物本身有问题（身份漂移、服装错、手被切）才重做。

## 禁止事项

- 不把人物做成灰模/黏土/去身份化的通用人形（灰模只用于确认版式，不是交付形态）。
- 不让第 4 格变成四分之三侧、或裁到胯部以下、或与前三格底边不齐。
- 不改变人物身份特征，也不添加照片里没有的配饰、图案、logo。
- 不在本业务 Skill 内选择 provider、模型版本、分辨率、轮询、下载或付费执行策略（属平台层职责）。
- 不提交媒体、不调用生成工具。
