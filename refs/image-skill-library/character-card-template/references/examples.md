# 标准角色卡 示例

> 示例不定义素材契约；仅展示组织方式与完整度，供提示词写作对照。禁止用示例覆盖用户当前指令。

## 正例

以下骨架可直接复用。方括号内按照片替换；【版面】与【排版】两段里的数字与对齐语句**逐字保留**——它们才是控制排版的部分，少一句就会跑偏。

```
【参考图分工】参考图 1 是版式基准：只学习它的版面结构——上排四个图形并排、底边齐平，上排占画面高一半略多；下排三张头肩紧接其下，两者之间只留一条很窄的白带（不到上排高度的十分之一）；第 4 格明显比前三个宽且只拍到腰线。绝对不要参考参考图 1 的人物长相、发型、服装、颜色与材质，也不要把它当成同一个人。参考图 2、参考图 3 是人物本人：脸型、五官、发型、服装、体型全部照参考图画出；四格与三张特写必须是同一个人的同一张脸。

一张棚拍风格的写实角色参考卡（character model sheet），竖版 3:4，纯白无缝背景，柔和均匀的顶光加两侧补光，轻微落地阴影，人物站在平整地面上。

【身份】[性别、年龄段、脸型、眉毛、眼睛、鼻型、唇形、肤色、体型与肩宽]。
【发型】[长度、分缝、走向、鬓角、后脑轮廓]。
【服装】[上衣款式与领型与袖长、裤型、鞋、材质光泽]。
【配饰】[手表/眼镜/耳环等；没有就写"无配饰"]。

【版面分配】上排四个图形从上到下占画面高度约 52%，它们的底边（脚底）落在画面高约 59% 的位置；上排与下排之间只留约 6% 画面高的窄白带，不要更大；下排三张头肩特写占画面高约 34%，三张头几乎顶着上排的脚底线，底部贴齐画面下缘。

【排版 — 上排四格，底边齐平，但四格不等宽】
画面上半部分横排四个图形，四格的**下边缘落在同一条水平线上**，互不重叠：
第 1 格：正面全身，宽约占画面宽 19.5%，从头顶到脚底，脚底贴齐公共底边；正对镜头，双肩对称。
第 2 格：右侧面全身，宽约占 12%，人物朝向画面左方，露出完整侧面轮廓，脚底贴齐公共底边。
第 3 格：背面全身，宽约占 19.5%，只见后脑、后背与脚跟，脚底贴齐公共底边。
第 4 格（最右）：同一个人的**正面上半身近景**，宽约占 33%（是第 1 格的 1.6 倍，格子要明显比前三个宽）；正对镜头、头正颈直、双肩水平、双耳对称；头部宽度约为第 1 格的 1.5 倍；只拍到**腰线**——上衣下摆与裤腰之间那一段，画面在腰线处横切，这条腰线截断处就是第 4 格的下边缘、与前三格脚底齐平；因为放大拍摄，头顶比前三格低约 5%；双臂垂直贴身、完整落在格内，距左右边缘留白，不被切断。

【排版 — 下排三格头肩特写】
画面下半部分横排三个头肩特写，每张约占画面宽三分之一：左为正脸（正对镜头、双耳对称），中为四分之三侧脸（转向画面右约 45°），右为九十度正侧脸（完全朝画面右）。三张头部大小完全一致、头顶同一水平线、下缘统一裁到锁骨下缘，头部高约占画面高 34%，撑满整条下排。

【姿态】四格与近景统一自然站立：双臂自肩部向下外展约 40°，手掌朝内，双腿与肩同宽，视线平视；平视正交视角，无广角畸变。

【风格】写实人物摄影质感，皮肤与布料细节自然，白底干净，边缘锐利，无噪点。

【禁止】改变人物身份特征、美化脸型、换发型、换装、添加照片中不存在的配饰或图案、背景渐变、彩色、文字、水印、四分之三侧的第 4 格、裁到胯部以下的第 4 格、四格等宽、四格底边不齐、上下两排之间出现大片空白、下排头部大小不一。
```

## 反例

- **不传版式基准图**，只靠文字百分比 → 排间空隙会在 4%–20% 之间随机波动，同一提示词两次结果差别巨大。这是目前最容易犯的错。
- 传了基准图但没写"参考图分工" → 基准图里的灰模质感、人物长相会被带进成品。
- 只写"四个视角的角色卡 + 三张头像"，不写版面分配与排间空隙 → 模型上下排均分，中间留出 20% 的空白。
- 写"四格等宽" → 第 4 格放大后装不下，手掌被格子边缘切掉。第 4 格必须更宽（约 33%）。
- 把人物描述写成一串形容词（"帅气、精致、高级感"）→ 脸漂移成通用美型脸。
- 只写"半身/腰部以上"当裁切 → 模型给到大腿；要给锚点：**上衣下摆与裤腰之间**横切。

## 边界案例

- **只有正面照片**：说明侧面/背面为合理推断，卡仍按版式出；把"不添加照片中不存在的图案"写进禁止项。
- **照片是坐姿或半身**：姿态统一为直立四视图，身高与腿长按体型合理推断，先告知用户这是推断值。
- **用户要求保留照片里的姿势**：与"四格统一 A-pose"冲突，先确认取舍；若保留，则四格必须各自统一为同一姿势的四个角度，不能四格四种姿态。
- **用户要求改裁切（更松/更紧）**：只改第 4 格的裁切锚点，其余版面比例与排间空隙保持不变。
