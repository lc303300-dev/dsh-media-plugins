# 标准角色卡 示例

> 示例不定义素材契约；仅展示组织方式与完整度，供提示词写作对照。禁止用示例覆盖用户当前指令。

## 正例

以下是可直接复用的提示词骨架。方括号内按照片替换，其余排版语句**逐字保留**（这些句子就是在控制对齐）。

```
一张棚拍风格的写实角色参考卡（character model sheet），竖版 3:4，纯白无缝背景，柔和均匀的顶光加两侧补光，轻微落地阴影，人物站在平整地面上。

【身份】[性别、年龄段、脸型、眉眼、鼻唇、肤色、体型与肩宽]。
【发型】[长度、分缝、走向、鬓角、后脑轮廓]。
【服装】[上衣款式与领型与袖长、裤型、鞋、材质光泽]。
【配饰】[手表/眼镜/戒指等；没有就写"无配饰"]。

【排版 — 上排四格，底边严格齐平】
画面上半部分横排四个图形，四格的**下边缘落在同一条水平线上**，等宽等距、互不重叠：
第 1 格：正面全身，从头顶到脚底，脚底贴齐这条公共底边；正对镜头，双肩对称。
第 2 格：右侧面全身，人物朝向画面左方，露出完整侧面轮廓，脚底贴齐公共底边。
第 3 格：背面全身，只见后脑、后背与脚跟，脚底贴齐公共底边。
第 4 格（最右）：同一个人的**正面上半身近景**，正对镜头、头正颈直、双肩水平、双耳对称；头部宽度约为第 1 格的 1.5 倍；只拍到**腰部以上**，画面在腰线处横切，这条腰线截断处就是第 4 格的下边缘、与前三格脚底齐平；因为放大拍摄，头顶略低于前三格；双臂垂直贴身、完整落在格内，距左右边缘留白，不被切断。

【排版 — 下排三格头肩特写】
画面下半部分横排三个头肩特写：左为正脸（正对镜头、双耳对称），中为四分之三侧脸（转向画面右约 45°），右为九十度正侧脸（完全朝画面右）。三张头部大小完全一致、头顶同一水平线、下缘统一裁到锁骨下缘。

【姿态】四格与近景统一自然站立：双臂自肩部向下外展约 40°，手掌朝内，双腿与肩同宽，视线平视；平视正交视角，无广角畸变。

【风格】写实人物摄影质感，皮肤与布料细节自然，白底干净，边缘锐利，无噪点。

【禁止】改变人物身份特征、美化脸型、换发型、换装、添加照片中不存在的配饰或图案、背景渐变、彩色、文字、水印、四分之三侧的第 4 格、裁到胯部以下的第 4 格、四格底边不齐、下排头部大小不一。
```

## 反例

- 只写"四个视角的角色卡 + 三张头像"，不写底边齐平与腰线裁切 → 模型给四张等大全身图，第 4 格退化成第 4 个全身视角。
- 写"半身特写"而不区分上下排的裁切 → 上排第 4 格裁到腰、下排也裁到腰，下排变成胸像而非头肩。
- 把人物描述写成一串形容词（"帅气、精致、高级感"）→ 脸漂移成通用美型脸，与照片对不上。
- 在提示词里省略背面/侧面细节约束 → 衣服背面被凭空加上口袋或图案。

## 边界案例

- **只有正面照片**：说明侧面/背面为合理推断，卡仍按版式出；把"不添加照片中不存在的图案"写进禁止项。
- **照片是坐姿或半身**：姿态统一为直立四视图，身高与腿长按体型合理推断，先告知用户这是推断值。
- **用户要求保留照片里的姿势**：与"四格统一 A-pose"冲突，先确认取舍；若保留，则四格必须各自统一为同一姿势的四个角度，不能四格四种姿态。
