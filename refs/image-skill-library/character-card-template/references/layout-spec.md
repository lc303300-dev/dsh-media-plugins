# 标准角色卡版式规范（硬规则）

本文件是本 Skill 的核心资产：**版式与取景是固定的，卡面人物来自用户照片**。每次出卡都按这里的几何规则对齐，不得自行简化成"四张并排图"。

## 1. 画幅

- 竖版 3:4（用户确认制；未确认时先问，不要默认其他比例）。
- 纯白无缝背景，全幅无边框线、无文字区、无水印。

## 2. 上排：四格，底边严格齐平

上排占画面高度约 52%，四格等宽、等距、互不重叠；四格的**下边缘落在同一条水平线上**，像素级齐平。

| 格 | 内容 | 取景 |
| --- | --- | --- |
| 1 | 正面全身 | 头顶到脚底，脚底贴齐公共底边 |
| 2 | 右侧面全身 | 同上，人物转向画面一侧，露出完整侧面轮廓 |
| 3 | 背面全身 | 同上，只见后脑、后背、脚跟 |
| 4 | 正面上半身近景 | 只到**腰线**，腰线截断处就是该格下边缘，与前三格脚底同高 |

### 第 4 格的细则（最容易做错）

- **朝向必须正面**：头正、颈部垂直、双肩水平、双耳对称可见，与第 1 格同一朝向；不是四分之三侧，也不是侧面。
- **放大倍率**：头部宽度约为第 1 格头部的 1.35–1.6 倍。倍率过小时看不出"近景"，过大时手臂会横向撑出格子。
- **裁切位置**：只拍到腰部，胯部、大腿、膝盖、脚全部不出现；腰线截断边与脚底齐平。
- **头顶位置**：因为放大，第 4 格头顶会略低于前三格的头顶线（低约 5–10%），这是正确的，不要为了"头顶对齐"而缩小人物。
- **手臂处理**：双臂垂直贴身、不外展；袖口与上臂完整落在格内，距左右边缘留出可见白边。被左右边缘切断即为不合格。

## 3. 下排：三张头肩特写

下排占画面高度约 48%，三张等宽、等距。

| 位置 | 朝向 |
| --- | --- |
| 左 | 正脸，面朝镜头正前方，双耳对称 |
| 中 | 四分之三侧脸，转向画面同一侧约 45° |
| 右 | 九十度正侧脸，完全朝该侧 |

- 三张头部**大小完全一致**、头顶落在同一条水平线上。
- 下缘一律裁到**锁骨下缘**，构图统一；不出现胸口以下的躯干。
- 四分之三与正侧两张必须朝同一侧，保证整排视觉方向一致。

## 4. 造型与呈现

- 呈现为**写实人物摄影/棚拍质感**，卡面人物就是用户照片里的同一个人：脸型、五官、发型、肤色、体型、服装款式与配饰全部按照片，不做美化替换。
- 姿势统一为自然站立（A-pose：双臂自肩部向下外展约 35–40°，手掌朝内，双腿与肩同宽），四格与近景姿态一致。
- 光：柔和均匀的棚拍光，大面积顶光加两侧补光，轻微接地阴影（人物站在地面上），无硬投影、无影棚道具。
- 景深与透视：四格统一为平视、正交感视角，不要广角畸变；同一张卡里四格的焦段观感一致。

## 5. 对齐自检清单

出图后逐项检查，任一项不满足即视为该格需重做：

1. 上排四格底边是否在同一条水平线上（尤其第 4 格腰线是否与脚底同高）。
2. 第 4 格是否为正脸胸像、只到腰、双臂不被左右切。
3. 下排三张头部是否同大、同顶线、统一裁到锁骨。
4. 四格人物是否同一个体型与身高感，脚底是否都在基线上。
5. 背景是否纯白无杂物，阴影是否只在脚下。
6. 卡面是否就是照片本人（脸没漂移、没被替换成通用脸）。
