# 即梦「音频生成」（SeedAudio）使用经验笔记

调研日期：基于 2026 年公开资料整理。**未实测**：本笔记的信息来自官方博客、官方节点文档与第三方教程，
没有在即梦 Web 端实际跑过生成任务；标注「待确认」的条目需要在站内验证。

## 1. 能力定位

即梦官网的「音频生成」背后是字节 Seed 团队的 **Seed Audio** 模型。它不是 TTS，而是"音频创作模型"：
**一条提示词、一次生成**里同时产出多人对白（各自独立音色）、关键音效、环境声/氛围、背景音乐，
并把它们混成一条成品音轨。官方定位是"听见即看见"——声音直接参与叙事。

- 即梦国际版（Dreamina）当前模型名为 **SeedAudio 2.0**；国内即梦截图显示仍为 **SeedAudio 1.0**。
- 据官方博客，多数场景（影视、短剧、动漫、播客对话、直播带货、话剧、TTS）音频可用率已达 90%+。
- 一次生成 ≈ **2 分钟**音频，可基于参考音频继续延长，音色/表达保持一致（官方称可延续到几十分钟）。

## 2. 站内界面（来自首页截图，待确认细节）

创作者首页输入区，模型下拉选 `SeedAudio 1.0`，提示语：

> 输入台词并描述声音，可上传参考音频，通过 @ 可用多个音色，使用何种增强人声、音效与配乐。

参数行可见：`音频生成`（模式）、`SeedAudio 1.0`（模型）、`全能参考`、`音乐库`、`@`；右下有 `12 / 24` 计数。

对应到模型参数（见第 5 节）：`@` = 素材引用（`@Audio1..3`、`@图片N`），
`全能参考` = 多模态参考模式，`音乐库` = 内置音乐/预置音色素材，`12/24` 很可能是素材数量上限。

## 3. 提示词写法（核心经验）

模型对「清晰的音频导演指令」响应最好。好的提示词读起来像一份**迷你音频剧本**，不是一行 TTS 文本。

### 六段式结构（电影感音轨）

1. `[类型 + 环境 + 情绪]` —— 定风格、地点、基调
2. `[持续声床]` —— 全程铺底的那个主声音（火焰轰鸣、雨声、机房低频）
3. `角色名（音色属性 + 情绪 + 语速 + 可选参考标签）动作动词："台词。"`
4. `[具体音效或转场]` —— 一个支撑剧情节点的声音
5. 下一个角色，情绪递进
6. `[静默 / 收尾音 / 音乐提示 / 淡出]`

要点：
- **不要堆料**：一条强声床 + 几个精准提示，胜过十个随机音效。
- **写长**：上限 3000 字符，官方示例基本写满。删掉的每一句，都是把判断交还给模型。
- **把声音拼出来**：拟声词比命名更可靠（"拉链呲啦"、"铃叮铃铃由近及远"、"刀锋呼呼"）。
- **语言一致**：提示词语言与台词语言保持一致，否则口音容易不对。
- 音色描述写**年龄、口音、情绪、音色、语速**，不要只写"好听"或"专业"。

### SCENE 检查表（Morphic 版）

| 项 | 写什么 |
|---|---|
| 场景 | 天气、地点、情境、声学（回声/混响） |
| 角色 | 每个人在做什么、穿什么 |
| 音效与音乐 | 音乐氛围与风格、具体音效 |
| 声音说明 | 性别、年龄、口音、情绪、音色、语速 |
| 台词 | 每句话写在引号里 |

### 常用场景模板

- **多角色对白/广播剧**：写清剧本 + 每个声音的描述，模型负责选角与调度。
- **纯环境音床**（B-roll 铺底）：只描述环境，明说"无音乐、无对白、音量恒定、可循环"。
- **旁白/有声书**：定下讲述者音色后按场景分段推进，各段沿用同一参考音频保持一致。
- **广告/宣传片**：把节奏写进提示词，重音会落在该落的词上，音乐会在恰当处让位。

## 4. 时间轴控制（配音对齐的关键）

在台词开头写时间码，模型会调整语速与停顿，把这段表演**严格**放进该区间：

```
瑞恩（年轻男性，温暖嗓音）焦急地喊，略微喘着气："[5.5s:8.0s] 玛雅！等等，你今晚真的要走吗？"
```

- 官方称时间控制精度 **100ms**；无时间码的台词按自然节奏读。
- 这是"能把音轨贴到画面上不拉伸不裁剪"的前提——做视频配音/翻配时必须用。
- ⚠️ 时间戳仅在 **multilingual 版模型**可用（见第 5 节）。即梦站内 SeedAudio 1.0 是否开放，待确认。

## 5. 参考音色（TA2A）与参数

### 四种参考模式（ComfyUI 官方节点文档，最权威的参数视图）

| reference_mode | 说明 |
|---|---|
| `text only` | 全凭文字描述选声，提示词中不得出现 `@AudioN` |
| `audio reference` | 上传最多 3 段参考音频克隆音色，提示词中用 `@Audio1/2/3` 绑定到角色 |
| `image reference` | 用一张角色图推导音色（适合虚构/动画角色），不与音频参考同用 |
| `preset voice` | 选内置 TTS 2.0 音色，整个提示词由该音色朗读，不用 `@AudioN` |

### 参考音频硬约束

- 每段 **≤ 30 秒**，最多 **3 段**，**必须按 `@Audio1/@Audio2/@Audio3` 顺序连接、不能跳号**。
- 提示词里出现的最大编号不得超过实际连接的段数。
- 只上传当次任务或从素材库复用（系列内容反复用同一段参考，保持角色声音一致）。

### CLEAR 参考音频准备清单

干净（背景噪声少）· 每段 ≤30s · 情绪与目标表演一致 · 段内口音一致 · 段间房间底噪稳定。
标准参考片段建议：单人、单一情绪、无音乐、无第二人声、约 70–85 词、自然语速。

### 后处理参数（API/节点侧）

`sample_rate`（8000–48000，默认 24000）、`speech_rate`（−50~100，0 正常）、
`loudness_rate`（−50~100）、`pitch_rate`（−12~+12 半音）、`seed`（**结果非确定性，换种子不等于可控复现**）。
即梦站内是否暴露这些，待确认。

## 6. 已知短板（实测者反馈）

- 同一参考音色在不同场景下的**泛化一致性**仍有提升空间（该慢的地方不够慢）。
- **唱歌**能力有限，容易跑调（虽然"跑调得很真实"）。
- 人声偶有**电音感**。
- 一次 2 分钟是上限，长内容必须分段 + 参考音延续。
- **音乐**只适合短配乐/氛围床；想要"主歌-副歌"的完整歌曲，应换专门的音乐模型。
- 受版权约束：参考音色需有直接授权。

## 7. 与视频的配合（audio-first）

- 主流做法是"音频优先"：先生成完整声音场景（对白+音效+氛围+音乐），**再**拿它作为视频生成的基础/参考。
- 反向也成立：Seedance 视频模型自带音效/配乐，并且**音频可作为输入参考**（即梦 Seedance 2.0：
  音频输入 ≤3 个、总时长 ≤15s、需 MP3；Seedance 2.5 允许纯音频输入，音频 ≤10、总 ≤50、单条/总 2–30s）。
- 用 `@音频1` 这类标签在视频提示词里指定用途（配乐/节奏参考）。
- 失败模式提醒：三段音频各自生成会各有各的"房间感"，拼接缝听得出来；单次生成能消除这个缝。
