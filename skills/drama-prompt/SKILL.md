# 即梦短剧提示词（11 区块 · 逐镜行）

> **口径（2026-11-10 定，最高优先）**：提示词层的【画面内容】与【镜头】逐镜行**由 Agent 自己写**——直接由执行脚本改写成提示词语言，不调用 `creative_writer`，不再交给 Gemini 重写。Gemini 只负责导演脚本与布光／风格锁定。
>
> **为什么**：交给 Gemini 写提示词时，它会重新分组、丢特写开场、把合并好的任务拆碎——执行脚本定的分组到提示词层就失效了。Agent 按执行脚本逐镜改写，两层镜号才能一一对应、不被改写。

## 输入 / 产出

- **输入**：`01-执行脚本-正式版.md`（六列分镜 + **第七章任务级硬约束表**）+ `30-通用提示词包.md` + 素材（`图片N` 顺序）
- **产出**：`02-即梦提示词-可提交版.md`（每任务一段，11 区块）+ `校验报告.md`

**前置检查**：执行脚本没有第七章硬约束表 → 先回 `drama-exec-script` 补，不要直接写提示词。

## 一、改写方式（从执行脚本直接改写）

| 执行脚本 | → 提示词 |
|---|---|
| 任务 | 一个段（一个画布节点 / 一次生成） |
| 镜号区间 | 【镜头】逐镜行数 = 该任务镜数（【画面内容】是连续流，不写镜号） |
| 画面要点 | 【画面内容】`镜N：` 的主干（写发生什么） |
| 摄影角度 / 景别 / 备注 | 【镜头】`镜N 景别｜机位高度+角度+焦段｜运镜｜动作要点` |
| 开场景别 | 本段【镜头】第一行的景别，**必须照抄，不许改** |
| 切换桥 | 本段第一镜的镜头描述里必须出现该桥（脚步/面部/手部/衣摆特写） |
| 场景卡 / 台词 | 【参考】/【画面内容】的台词流 |

**禁止**：重新分组、增删镜、改镜号顺序、把两个任务合并成一段、把一段拆成两段。

## 二、11 区块（顺序不可变）

```
【风格】【布光锁定】【参考】【设定】【特殊要求】【导演】【故事背景】
【画面内容】【镜头】【一致性】【限定】
```

逐块写法见 `drama-tvc-prompt/references/jimeng-drama-template.md`；【镜头】逐镜行六要素见 `shot-level-rendering.md`。

| 谁写 | 区块 |
|---|---|
| **Agent 自己**（本技能） | 【画面内容】+【镜头】逐镜行、全部常量块装配 |
| Gemini（本技能之前已产出） | 【布光锁定】、【故事背景】（来自 `drama-style-pack` 的产出） |
| Agent 拼装 | 【风格】【参考】【设定】【特殊要求】【导演】【一致性】【限定】 |

## 三、逐镜行格式（六要素）

```
镜头一（0-1.4秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 35mm（中景），低角度（low angle）固定拍摄（static shot）；爸爸从右侧入水，肩背发力，水花在肩侧翻起。
```

- 时间戳闭环：第一镜从 0 开始，逐镜相接，末镜 = 本段时长，无重叠无空档
- 每镜必须写光圈（景深）+ 焦段（景别）+ 机位运镜 + 主体动作 + 落点
- **画面内容与镜头严格分开**：画面内容只写发生什么，镜头只写怎么拍（见 `ai-video-shooting-rules.md` 第八节）

## 四、硬规则（来自 `ai-video-shooting-rules.md`，优先级最高）

- 参考图禁止 1:1 构图：每个镜头重新架机位（高度 + 角度 + 焦段 + 前后景）
- 有人物换场只用人物局部特写硬切；每任务 ≥3 景别；禁一镜到底
- 动作先局部特写、再中景/全景；主体描述全正面表述
- **切换场景卡后的第一镜必须是特写**（片头建立镜例外）
- 【限定】第一条必须是「禁止加背景音乐」
- 台词放单人镜、按语速核时长；镜数按 1.5–2.5 秒/镜

## 五、机械校验（必跑）

```bash
python assets/check_prompts.py 02-即梦提示词-可提交版.md --expected tasks.json
```

`tasks.json` 从执行脚本第七章抄：`[{"task":"T01","shots":3,"seconds":9,"open_shot":"特写"}, …]`

校验项：每段 11 区块齐全、**镜头行数 == 执行脚本该任务镜数**（画面内容不写镜号）、时间戳闭环、开场景别与执行脚本一致、`图片N` 绑定存在、禁用写法（管道符标题 / `@图片` / fps / 文件名）、单段字数。任一项失败 → 回改，不许带 ❌ 提交。

## 六、验收清单

- [ ] 每段对应执行脚本里**同一个任务**，没有合并/拆分
- [ ] 【镜头】行数 == 执行脚本该任务镜数；【画面内容】是连续流、不写镜号
- [ ] 每段第一镜的景别 == 执行脚本「开场景别」（切换场景卡后是特写）
- [ ] 切换桥出现在第一镜的镜头描述里
- [ ] 时间戳闭环、六要素齐、11 区块齐全
- [ ] 【限定】第一条是「禁止加背景音乐」
- [ ] `check_prompts.py` 全绿

## 七、提交

提交走 `drama-shoot`。`prompt_batch set_prompts` / `generate_video` 的创作门仍会查 24h 内 `creative_writer` 记录——按 2026-11-10 分工提示词由 Agent 写，提交时传 `allow_manual_prompts: true` + `manual_prompts_reason: "2026-11-10 分工：提示词层由 Agent 从执行脚本改写"`，不要静默手写。
