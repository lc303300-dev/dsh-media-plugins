# 执行脚本（防错配闸门）

> 这一层是整个短剧流程里**返工最多**的地方。三个真实项目里最严重的返工，全部发生在"跳过这一层"或"这层没写死"的时候。
>
> **本层是 Agent 自己的活**（2026-11-10 分工），不调用 `creative_writer`。

## 输入 / 产出

- **输入**：`00-导演骨架.md`（九列分镜表 + 任务划分草稿）+ 素材清单（场景卡 / 角色卡 / 道具卡 / 音色）
- **产出**：`01-执行脚本-正式版.md`，六章 + **第七章任务级硬约束表**

## 一、六个章节（顺序固定）

| 章节 | 内容 | 作用 |
|---|---|---|
| 一、剧本定稿 | 场次 / 角色 / 台词 三列表，逐句锁定 | 台词进入不可变状态 |
| 二、台词 → 场景卡映射 | 台词关键句 / 对应场景卡 / 所在任务 | **核心防错机制** |
| 三、分镜表 | 六列（见下） | 把导演视角转成生产视角 |
| 四、任务划分 | 任务 / 镜 / 时长 / 场景 / 素材数 + 合计 | 决定产出几段提示词 |
| 五、执行备注 | 本项目专属修正项 | 历史教训固化成约束 |
| 六、参考图使用清单 | 文件（`图片N`）/ 用于任务 | 素材与任务对应 |
| **七、任务级硬约束表** | 开场景别 / 场景切换 / 切换桥 / 镜数 / 时长 | **防"特写开场被忽略、镜头被拆散"** |

## 二、九列 → 六列压缩

```
| 镜 | 时长 | 场景卡 | 台词 | 画面要点 | 任务 |
```

| 九列 | 六列 | 说明 |
|---|---|---|
| 镜号 | 镜 | 原样 |
| 时长 | 时长 | 原样 |
| 场景 | 场景卡 | 文字场景名 → 具体素材（SC01/SC02…） |
| 画面内容 | 画面要点 | 收敛成一句「谁在哪、做什么」 |
| 摄影角度 / 景别 / 备注(运镜) | — | 收起，留给提示词层展开成逐镜行 |
| 声音 | 台词 | 只留台词；环境声进【设定】 |
| 叙事目的 | — | 不进执行脚本，是导演判断依据 |
| — | 任务 | 新增：这一镜归属哪个生成任务 |

## 三、台词 → 场景卡映射（没做完不许写提示词）

```
| 台词关键句 | 对应场景卡 | 所在任务 |
| 这入户电梯厅约16平 / 收纳间 | 入户电梯厅（SC02） | T02 |
```

做表时三类错会立刻暴露：**说了但没图**（补素材或改画面）、**有图但没用**（查漏卖点）、**图文错位**（拆任务或换图）。
提示词写完后还要**反向再查一遍**：正文提到的每个空间/道具，是否都在本段素材绑定里。

## 四、任务划分（分组在这一层定死）

### 4.1 三条数值约束

| 约束 | 数值 |
|---|---|
| 单任务时长 | 4–15 秒（模型上限 15 秒；不足 4 秒按 4 秒生成，多出的时间给动作留白） |
| 单任务镜数 | **2–4 镜**（超过 4 镜模型开始丢镜；1 镜只允许 2 秒以内的插入镜） |
| 单段提示词字数 | 2400–3000 字（硬上限 4000） |

### 4.2 合段三条件（满足任一、且必须"连续"）

| 条件 | 说明 |
|---|---|
| 素材共用 | 相邻镜头用同一组参考图（同一空间、同一批人物） |
| 时空连续 | 同一场景同一时刻，中间没有跨越 |
| 叙事单元完整 | 几个镜头合起来表达一个完整动作或意思 |

**不该合段**：换场景 / 换时间、中间有硬切转场（叠化、黑场、快切）、合起来超过 15 秒。

### 4.3 四秒下限

某段算出来只有 2–3 秒 → 生成仍填 4 秒；某镜只有 1 秒 → 必须与相邻镜合段。

## 五、第七章：任务级硬约束表（本技能的核心）

**这张表是"规则不靠自觉"的落点。** 每个任务一行，字段固定：

```
| 任务 | 镜号 | 时长 | 场景卡 | 素材数 | 开场景别 | 场景切换 | 切换桥 | 镜数 | 景别数 | 校验 |
| T01 | 1-3 | 9s | SC01 | 3 | 特写 | — | — | 3 | 3 | ✅ |
| T02 | 4-6 | 8s | SC05 | 4 | 特写 | 是 | 脚步特写（迈过门槛） | 3 | 3 | ✅ |
```

字段定义（全部必填，缺一项即不合格）：

| 字段 | 规则 |
|---|---|
| 开场景别 | **必须是特写**；片头建立镜可为中全景；同一场景延续可写「承接」 |
| 场景切换 | 本任务首镜场景卡 ≠ 上一任务末镜场景卡 → 填「是」 |
| 切换桥 | 场景切换为「是」时必填，且必须是人物局部特写（脚步 / 面部 / 手部 / 衣摆），不许用空镜或环境全景 |
| 镜数 | 2–4（1 镜仅限 ≤2 秒插入镜） |
| 景别数 | ≥3（1 镜任务不适用） |
| 校验 | 跑完脚本后填 ✅ / ❌ |

**为什么必须写在这里**：实测"切换场景后要特写开场""散落镜头要合段"这两条规则写在提示词层的文档里，模型会忽略；写进执行脚本的硬字段、再由脚本机械校验，才不会漏。提示词层只按这张表改写，不许重新分组。

## 六、机械校验（必跑）

```bash
python assets/check_exec_script.py 01-执行脚本-正式版.md
```

校验项：任务镜数 2–4、时长 4–15、场景切换必填切换桥、切换桥必须是特写类、开场景别合规、镜号不重叠不跳号、合计时长与目标一致。**任一项失败 → 回改执行脚本，不许带着 ❌ 进提示词层。**

## 七、验收清单（逐项打勾）

- [ ] 六章齐全，第七章硬约束表每个任务一行
- [ ] 台词 → 场景卡映射逐句成立，反向复查通过
- [ ] 每任务 2–4 镜、4–15 秒、≥3 景别
- [ ] **切换场景卡后的第一镜是特写**，且切换桥是人物局部特写
- [ ] **同场景卡、时空连续的散镜已合进同一任务**（没有为了凑任务硬拆）
- [ ] 没有"说了但没图 / 有图但没用 / 图文错位"
- [ ] `check_exec_script.py` 全绿

## 八、常见返工（按用户原话）

| 用户说 | 含义 | 改法 |
|---|---|---|
| 配图和台词完全对不上 | 映射表没做或没核对 | 重做第二章 |
| 镜头之间像是强行拼接 | 缺切换桥 | 补出点→入点→切换桥 |
| 每个小空间都硬切一遍 | 没合段 | 按 4.2 三条件合段 |
| 太久了 | 任务超 15 秒 | 减镜，不是压时长 |
| 特写开场又没了 | 硬约束表没写或没校验 | 补第七章 + 跑脚本 |
