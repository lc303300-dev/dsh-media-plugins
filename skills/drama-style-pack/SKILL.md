# 通用提示词包（7 常量块 + 布光锁定）

> 规则依据：`drama-tvc-prompt/references/lighting-modules.md`（三套现成模块 + 8 维度拆解法）；布光硬规则：`video-director-prompt/references/lighting-lock.md`（先要图 → Gemini 一次看图写完 → Agent 只校准事实与拼接）。

## 输入 / 产出

- 输入：项目定位 + 参考图（整体图 + 每个时段/光源各一张）
- 产出：`30-通用提示词包.md`（7 块全文，后面每段整块复制）

## 7 个常量块

| 块 | 谁写 | 要点 |
|---|---|---|
| 【风格】 | Agent | 一句话影调定调 + 「超写实」 |
| 【布光锁定】 | **Gemini 看图写** | 纯英文，8 维度：影调参照 / 机身镜头 / 色彩锚点 / 曝光影调 / 光源色温 / 运动 / 情绪 / 声源 |
| 【设定】 | Agent | 语言 + 表演基调 + 有无台词 |
| 【特殊要求】 | Agent | 私密空间清空 vs 公共空间克制，背景人物规则 |
| 【导演】 | Agent | 身份锚定一句话 |
| 【一致性】 | Agent | 面孔 / 服装 / 道具 / 空间 / 光源锁定，写到道具级 |
| 【限定】 | Agent | 四条负向禁止，**第一条必须是「禁止加背景音乐」** |

## 布光锁定（最重要，必须看图）

1. **先向用户要图**：一张整体图 + 每个时段/光源各一张。没有图不要自己写。
2. **一次调用**把整体图与所有分时段图一起传给 `creative_writer`，一次写完「整体风格锁定 + 模块化布光锁定」。
3. brief 只给「片子基本事实 + 图序对应什么 + 输出格式」，不要塞元规则。
4. 用纯英文，写成「手绘画面里的光」或「实拍里的光」按片子类型定，不写 sensor / film grain 这类无关参数。

## 互斥检查（必做）

逐对检查：禁音效 vs 写环境声、绝对无外人 vs 允许虚化路人、禁止文字 vs 场景标识保真——**互相打架的条款只留一条**。

## 验收

- [ ] 7 块齐全，【限定】第一条是「禁止加背景音乐」
- [ ] 【布光锁定】是 Gemini 看图写的，不是套模块原文
- [ ] 8 维度齐全，纯英文
- [ ] 互斥检查通过
- [ ] 一致性写到道具级（服装 / 配饰 / 痣 / 身高比）

## 常见返工

- 「灰 → 影调不对」→ 调布光；
- 「刻意 → 手法过载」→ 去重复（同手法连用 ≥2 次即删）。判断见 `guided-production-flow.md` 的 8 族词。
