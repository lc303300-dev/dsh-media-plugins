# 短剧生产 · 引导式流程（Agent 执行手册）

> **这是给 Agent 的：拿到用户的大纲后，按这份手册一步一步带他走完，不要一次性输出。**
>
> 规则依据（为什么这样做、量化基准、验收词典）在 `outline-to-jimeng-pipeline.md`，本文只讲**怎么带**。

---

## 0. 启动识别

用户的启动方式通常是两类之一：

| 类型 | 用户说什么 | 你要做什么 |
|---|---|---|
| **A. 直接给大纲** | 「这是脚本：<路径/文本>」 | 进入 Step 0 |
| **B. 宣告阶段** | 「素材准备好了，我们进入导演剧本制作」 | 跳过 Step 0–1，从 Step 2 开始 |

**识别到启动后，第一句只做一件事**：确认入口 + 说明接下来会分几步走、每步他会看到什么。

```
收到。我按 7 步带你走完，每步产出先给你看，你点头我再走下一步：

0 诊断与信息点 → 1 台词定稿 → 2 导演脚本 → 3 执行脚本 → 4 通用提示词包 → 5 即梦提示词 → 6 交付/上画布

先告诉我三件事（其余我自己读文件）：
① 成片时长目标？（不确定的话我按台词量给你算一个）
② 素材现状？（已有场景卡+角色卡 / 还没有 / 部分有）
③ 有没有硬性禁止项？（不要字幕 / 不出现路人 / 不出现某场景…）
```

> **纪律**：一次最多问 3 个问题。能从文件里读到的，绝不问。

## 1. 七步总表

| 步 | 名称 | 产出 | 给你看什么 | 放行条件 |
|---|---|---|---|---|
| **0** | 诊断与信息点 | `00-诊断报告.md` | 信息点清单（N 条）+ 四类问题 + 建议时长 | 你确认信息点无遗漏 |
| **1** | 台词定稿 | `01-台词定稿.md` | 逐句对照 + 信息点核对表（N/N） | 你确认台词 |
| **2** | 导演脚本 | `00-导演骨架.md` | 导演定调 + 九列分镜表 + 任务划分 + 12 项自检 | 你确认分镜 |
| **3** | 执行脚本 | `01-执行脚本-正式版.md` | **台词→场景卡映射表** + 任务划分表 | 你确认映射 |
| **4** | 通用提示词包 | `30-通用提示词包.md` | 7 个常量块全文 | 你确认调性 |
| **5** | 即梦提示词 | `02-即梦提示词-可提交版.md` | 段目录 + 机械校验报告 + 每段区块 | 你确认可提交 |
| **6** | 交付 | `.docx` + 可选画布节点 | 文件清单 | 你验收 |

**三个强暂停点**（必须拿到明确放行）：**Step 1 / Step 3 / Step 5 之前**。
理由：这三处改一次，下游全部重做。

## 2. 每步协议

### Step 0｜诊断与信息点

**我要做的**

1. 读大纲全文（docx 用 python-docx 提取，md/txt 直接读）
2. 拆出**信息点清单**：把台词逐句拆成信息点，编号（一句通常 2–4 条）
3. 四类诊断：时长/台词量不匹配、台词书面化、逻辑常识硬伤、术语品牌口径
4. 按 `台词字数 ÷ 4.5 字每秒 + 动作镜头秒数` 反算建议时长
5. **忽略并推翻**脚本自带的任何时间标注

**产出** `00-诊断报告.md`：

```markdown
# 诊断报告
## 一、信息点清单（共 N 条）
| # | 所属场次 | 信息点 | 出处句 |
## 二、四类问题
| 类型 | 问题 | 建议处理 |
## 三、时长核算
台词 X 字 ÷ 4.5 = Y 秒；动作/空镜 Z 秒；建议总时长 Y+Z 秒
## 四、需要你确认的三件事
```

**给你看**（不超过 40 行）：信息点条数 + 四类问题各一条最典型的 + 建议时长 + 需要你定的选项。

**放行**：用户说「可以 / 继续 / 跑吧」或指定了修改。

**常见返工**：用户说「你默认都没有」→ 意思是别假设他有素材，没有就说没有，并给出"要准备什么"的清单。

---

### Step 1｜台词定稿（信息点清单法）

**我要做的**

1. 把信息点清单 + 字数配额一起交给 LLM（`creative_writer`，kind=script，thinking=high）
2. **两轮**：第一轮只求自然（会写胖）；第二轮只瘦身（删水不删信息）
3. 逐条核对信息点，输出 N/N
4. 台词逐句锁定，进入不可变状态

**给 LLM 的措辞（照抄）**：

```
下面是台词的信息点清单（N 条）与字数配额（X 字 ± 10%）。
请把这些信息点全部保留，用口语重写；不要求保留原句措辞。
改写后我会逐条核对信息点，缺一条即不合格。
```

**产出** `01-台词定稿.md`：

```markdown
# 台词定稿（N 句 / X 字）
| 场次 | 角色 | 台词（定稿） |
## 信息点核对
| # | 信息点 | 落在哪句 | ✓ |
```

**给你看**：逐句对照（原文 → 定稿）+ 「信息点 N/N 全在」+ 改动的类型（只允许：口语化/合句/调顺序/去赘词）。

**放行**：用户确认。

**常见返工（按用户原话处理）**：
- 「改得有些多了」→ 回退，只保留必要改动
- 「有些太拘谨了」→ 放开，不要逐字守壳
- 「不要中途停靠一次，不要去加这种负面信息」→ 删掉所有负面/绕路的添加
- 「把每句话拆得太碎了」→ 一段话整体交给 LLM，不要一句一句喂

---

### Step 2｜导演脚本

**我要做的**

1. **一次写完，不分段**（分段会导致后段衰减）
2. 先定调（六维 + 七项视听决策 + 意象体系），再节奏（双轨 + 镜头组），再九列表
3. 九列分镜表：`镜号|时长|摄影角度|景别|画面内容|场景|声音|备注|叙事目的`
4. 每镜只装一个信息；时长按 2–3/4–5/6–8/6–10 秒基准
5. 任务划分（素材共用 + 时空连续的连续镜头合为一段，4–15 秒，2–4 镜）
6. 跑 12 项自检
7. **给 LLM 看图**（把场景卡/角色卡拼成大图版，不逐张给）

**产出** `00-导演骨架.md`：定调 / 节奏 / 九列表 / 任务划分 / 12 项自检 / 下一步输入

**给你看**：导演定调一段话 + 九列表全表（这是核心，必须全看）+ 任务划分表 + 自检结论。

**放行**：用户确认分镜。

**常见返工**：
- 「太久了」→ 减镜（不是压时长）
- 「每个小空间都硬切一遍」→ 并镜
- 「镜头之间像是强行拼接」→ 补衔接设计（出点→入点→手段）
- 「不要一镜到底 / 不要创意转场」→ 改常规切
- 「多打角色特写」→ 特写三件套：脚步=进新地点 / 手=微观动作 / 眼神=看到了什么（后接看到的物体）

---

### Step 3｜执行脚本（防错配闸门）

**我要做的**

1. 台词逐句锁定（从 Step 1 拿）
2. **做「台词 → 场景卡」映射表**（最重要，没做完不许写提示词）
3. 九列压成六列：`镜|时长|场景卡|台词|画面要点|任务`（摄影语言收起，留给 Step 5）
4. 任务划分表（任务/镜/时长/场景/素材数 + 合计）
5. 执行备注：本项目专属修正项
6. 参考图使用清单（文件 → 用于任务）
7. **反向再查一遍**：每段正文提到的空间/道具，是否都在本段素材绑定里

**产出** `01-执行脚本-正式版.md`（六章）

**给你看**：映射表全表 + 任务划分表（含合计秒数）+ 执行备注。

**放行**：用户确认映射。

**这一步必查的三类错**：
1. 说了但没图（台词说学校，素材没学校）→ 补素材或改画面
2. 有图但没用（准备 18 张只用了 6 张）→ 查是否漏卖点
3. 图文错位（一段里说 A 拍 B）→ 拆任务或换图

**常见返工**：「配图和台词完全对不上」→ 就是这张表没做或没核对。

---

### Step 4｜通用提示词包

**我要做的**

1. 写 7 个常量块：【风格】【布光锁定】【设定】【特殊要求】【导演】【一致性】【限定】
2. 【布光锁定】**用英文写，8 维度**（影调参照/机身镜头/色彩锚点/曝光影调/光源色温/运动/情绪/声源）
3. 【特殊要求】写清私密空间 vs 公共空间的背景人物规则
4. 【一致性】写到道具级（服装/配饰/痣/身高比）
5. **逐对检查互斥**（禁音效 vs 写环境声、绝对无外人 vs 允许虚化路人、禁止文字 vs 场景标识保真）

**产出** `30-通用提示词包.md`（7 块全文，后面每段整块复制）

**给你看**：全文（很短，必须全看，这是全片视觉指纹）。

**放行**：用户确认调性。

---

### Step 5｜即梦提示词

**我要做的**

1. 按 Step 2 的任务划分，逐段生成
2. **变量块**（【参考】【故事背景】【画面内容】【镜头】）交 LLM 写，**给图**
3. **常量块**（7 块）Agent 从 Step 4 整块复制，一个字不改
4. 【参考】块写「图片N为X」，顺序**角色在前、场景在后**；正文**只写角色名**
5. 【镜头】逐镜行六要素：时间戳 + 光圈(景深) + 焦段(景别) + 机位运镜 + 主体动作 + 落点
6. 跑机械校验（区块/时间戳闭环/镜数/字数/禁用词/素材数/常量块一致）

**产出** `02-即梦提示词-可提交版.md` + `校验报告.md`

**给你看**：段目录表（段/场次/时码/段时长/镜号/素材数）+ 校验报告 + 前 1–2 段全文（其余按需翻）。

**放行**：用户确认可提交。

**七个「不」**：不写负面词、不写字幕、不写 BGM、不写心理/比喻、不写小数秒、不写文件名、不多机位并联。

---

### Step 6｜交付

**我要做的**

1. 全部产物转 docx（**必须设东亚字体**，否则中文乱码）
2. 需要上画布时：上传素材 → 建素材节点（四类建全）→ 建视频卡（`--count 1`，m2v）
3. 绑素材用 `--ref node:<id>`，prompt 内联 `{{node:xxx}}`
4. **不传 `--run`**（付费动作归用户手动开始）
5. 改卡用 `node edit video --node-id`，**禁止 delete + create**

**给你看**：文件清单 + 画布链接（用 Chrome 打开）。

## 3. 放行与返工协议

### 3.1 判「过了」还是「没过」

**过了** = 用户给出下一个执行动词：`跑吧 / 开始 / 都开始吧 / 全部开始 / A / 写入吧`。

**没过** = 出现这 8 族词之一：

| 族 | 含义 | 改法 |
|---|---|---|
| 多 | 做过头 | 减 |
| 碎 | 粒度太细 | 并 |
| 快 | 节奏不对 | 调时长短 |
| 假 | 不像真的 | 换说法/换动作 |
| 灰 | 影调不对 | 调布光 |
| 刻意 | 手法过载 | 去重复（同手法连用≥2次） |
| 奇怪 | 逻辑/空间不成立 | 查空间动线连续性 |
| 对不上 | 素材错配 | 查映射表 |

**低层不合格时用户不会提高层**——先修逻辑，再谈审美。

### 3.2 改法粒度

```
改一句 → 问题只涉及某句台词/某个动作
改一段 → 涉及机位、景别、镜头顺序
整片重写 → 涉及节奏、结构、人物关系
```

### 3.3 三条铁律

1. **改卡不删卡**（删了再建会丢上游连线）
2. **给 LLM 看图，不要只给文字**（否则它会发明空间）
3. **每步产出先给用户看，再走下一步**（不要连续跑多步）

## 4. 素材前置分支

Step 0 若确认「素材还没有」，先走素材准备（可并行）：

| 素材 | 规格 | 产出 |
|---|---|---|
| 角色卡 | 3:4，正面全身，同角色多套服装 | `00-角色卡/` |
| 场景卡 | 16:9，按剧本场景逐张 | `06-场景卡/` |
| 道具卡 | 1:1，只出需要的 | `06-道具设定/` |
| 音色 | 每人一段基准台词 | `声音模板/` |
| 全家比例 | 3:2 同框，锁身高比例 | `角色卡/` |

**素材纪律**：

- 素材是**意向**，不是构图命令：参考图提供材质、色彩、光线、人物长相，**不提供景别与构图**
- 素材多时**拼接成图版**再给 LLM（不逐张给）
- 素材要**筛**不要凑：有图但不该用就不用（用户会核对是否真用上了）
