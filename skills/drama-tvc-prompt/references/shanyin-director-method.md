## 一、核心主张

> 将剧本转化为可执行的视听方案。核心理念：**每一个镜头都有叙事目的，每一次剪辑都有节奏意图，每一个视听选择都服务于故事。**

铁律（优先级最高）：

### 写作红线

- **绝对不要**：写心理描写（"他意识到"）、写括号暗示（"（其实是在掩饰紧张）"）、
  在画面内容或叙事目的中写任何摄影机拍不到的内容、说教片段、AI 腔的过度比喻
- **必须做到**：画面内容只写**可见**的动作和物体；声音列只写**可听**的声音；
  叙事目的用**客观分析**语气、具体到视听手段；台词**口语化**

### 工作流纪律

- 严格按步骤顺序执行，**不跳步**
- 每一步完成后**暂停**，等待用户的 `[通过 / 修改 / 自检]` 指令
- 绝不一次性生成所有内容

### 输入兼容

| 输入类型 | 说明 |
|---|---|
| 标准剧本（`【场景X：地点/时间】` + 对白 + 动作） | 直接进入工作流 |
| 用户自己写的粗糙文本 | 先做一轮剧本梳理 |
| 故事大纲/梗概 | 先整理成场景结构 |
| 已有分镜的修改需求 | 对分镜表做调整 |

## 二、五步工作流

```
第一步 导演定调 → 第二步 节奏规划 → 第三步 剧本微调 → 第四步 分镜拆解 → 第五步 输出 xlsx
```

每步结束**暂停**，等 `[通过 / 修改 / 自检]`。

### 第一步：导演定调

**输入**：剧本（或整理后的文本）
**输出**：导演定调方案（含维度参考、融合方案、七项视听决策、意象体系）

1. 从**六个维度**判断剧本涉及哪些（见下节「六维定调法」）
2. 从各维度导演风格模板库提取 **2-3 个有差异**的导演方向
3. **分轮引导式提问**确认用户倾向（不直接把导演菜单给用户看）
4. 输出完整定调方案

### 第二步：节奏规划

**输出**：场景级节奏规划（含镜头组划分）

1. 逐场标注**双轨节奏**（情节松紧 + 情感轻重）
2. 叠加导演执行层（镜头密度、景别重心、预估时长、转场策略）
3. **划分镜头组**：一场戏内哪些镜头的叙事目的由一组紧密相接的镜头共同完成
4. 输出全片节奏波浪图（导演版）
5. 做节奏诊断

### 第三步：剧本微调

**输出**：微调后的剧本

1. **视听化修正（前置）**：只修改无法被摄影机拍到的东西
2. **四焦点微调**：表演节奏 / 台词对白 / 画面内容 / 意象落地
3. 所有微调按焦点分组，用**对比格式**输出（原文 → 微调 + 理由）
4. 无需微调时明确告知并说明原因

**边界**：不改核心戏剧动作和人物弧光方向。

### 第四步：分镜拆解

**输出**：Markdown 格式的分镜表（九列）

1. 逐场进行**叙事目的分析**
2. 按叙事目的 + 导演定调 + 节奏规划逐镜拆解
3. 生成九列标准格式分镜表（Markdown 预览版）
4. **按场景/段落分批输出**（不一次性生成全片）

**分批规则**：短片（5分钟内）可一次或分 2-3 批；中片（5-15分钟）分 3-5 批；长内容每次一个段落。

**自检要点**：每镜是否有叙事目的、是否具体到视听手段、画面内容是否只含可见元素、
时长是否合理、相邻镜头景别/角度连接是否有视觉逻辑、对白场景处理是否多样、意象是否落地、
镜号是否连续、**Double Check 三层**（影调一致性 / 节奏匹配 / 每场戏约 20% 出彩设计）。

### 第五步：输出 xlsx

Markdown 分镜表 → xlsx，按 `storyboard-format.md` 第五节规范（列宽/表头/自动换行/镜号居中）。

## 三、叙事目的分析法

### 定义

> 叙事目的是一场戏（或一个镜头）在全片叙事中承担的功能：**"这段内容为什么必须存在？删掉它，全片会缺少什么？"**

两个层面同时覆盖：

**结构层（叙事功能）**：交代信息 / 建立角色 / 推进情节 / 埋伏笔回扣 / 呈现主题 / 首尾呼应 / 呼吸点

**导演执行层（视听意图）**：制造不安感 / 控制视线 / 营造氛围 / 制造时间感 / 视觉隐喻 / 标记层次切换 / 建立或打破预期

### 四遍提取法

1. **结构性通读**：全片骨架图——标注每场核心事件与价值转变（McKee 标准：这场戏开始和结束时核心价值是否不同）
2. **功能标注**：逐场标注结构层叙事目的（每场 1-3 个；找不到就应考虑删除或合并）
3. **导演意图叠加**："我要用什么视听手段让这个结构功能生效？"
4. **合并为分镜表叙事目的列**：一句话覆盖"做什么 + 为什么这么做"，具体到视听手段

### 好的叙事目的写法

- "交代故事发生的空间背景与核心视觉设定（蓝线及其初始高度）。"
- "形成视觉与叙事上的双重闭环，开启属于 Steve 的新一轮情感循环。"
- "用背对镜头的构图展现疏离"（✅ 具体到手段）而非"展现他们的关系变化"（❌ 空泛）

### 自检

- [ ] 每场戏是否至少有一个叙事目的？（无目的的戏应删或合并）
- [ ] 全片叙事目的是否均匀分布？（信息交代是否过度集中在前段）
- [ ] 伏笔/回扣是否成对出现？
- [ ] 主题是否通过**视听动作**而非台词传达？
- [ ] 呼吸点是否存在？（连续三场高强度后需要一场节奏调节）

## 四、六维定调法

不是只选一个"类型"，而是从六个维度综合考量，最终融合为一套视听方案。**一个项目通常涉及 2-4 个维度。**

| 维度 | 核心问题 | 参考文件（原项目） |
|---|---|---|
| A. 情绪基调 | 影片的情感温度和审美姿态是什么？ | `genre-A-mood.md`（日常写实/情绪美学/诗意冥想/荒诞/悲剧/喜剧/黑色幽默/浪漫） |
| B. 类型片 | 遵循什么类型惯例？在哪里打破？ | `genre-B-genre.md`（惊悚/心理惊悚/恐怖/犯罪/黑色电影/悬疑/科幻/奇幻） |
| C. 动作与对抗 | 身体对抗如何产生冲击力和叙事意义？ | `genre-C-action.md`（现代动作/武侠/战争/灾难） |
| D. 题材与关系 | 如何用视听呈现人与人的关系和情感？ | `genre-D-theme.md`（爱情/家庭亲情/青春成长/传记/体育/悲剧） |
| E. 叙事形式 | 叙事形式本身对视听有什么特殊要求？ | `genre-E-form.md`（伪纪录片/公路片/歌舞片/动画/实验先锋） |
| F. 社会视角 | 影片如何处理与现实社会/历史的关系？ | `genre-F-social.md`（社会现实主义/历史古装/政治讽刺/主旋律） |

**交叉组合示例**：黑色幽默公路片 = A7 黑色幽默（科恩兄弟）+ E2 公路片（佩恩）+ D1 爱情（林克莱特的对话方式）

**融合时确定**：一个"主导导演参考" + 若干"局部借鉴"。

### 引导式提问（四轮）

1. **情绪和类型大方向**："你希望观众看完最大的感受是什么？""只用一个词形容它的气质？"
2. **视听风格偏好**："有没有哪部电影的画面感觉是你想要的？""你最不想要什么（太花哨/太慢/太暗）？"
3. **题材和形式**："有没有特殊叙事形式？核心关系是哪一种？"
4. **社会历史维度**（如需要）："和现实的关系是什么？"

**方向的呈现方式**：描述"这种视听风格会让影片变成什么样"，导演名字只作参考点提及。

### 定调输出格式（七项视听决策 + 意象体系）

```
【视听姿态】摄影机作为[XX]，与角色保持[XX]距离
【维度参考】情绪基调/类型方向/题材关系…（各注明核心参考的导演方法论）
【融合方案】整体基调 + 段落局部借鉴
【镜头语言】固定/手持/混合 + 长镜头/快切/混合
【构图方向】对称/不对称/自然 + 留白/密集
【色调光线】暖/冷/去饱和 + 自然光/戏剧光/实际光源
【剪辑节奏】快/慢/变化 + 线性/非线性
【声音设计】配乐驱动/辅助/极少 + 环境声写实/风格化
【叙事视角】全知/限制/多视角 + 观众信息量大于/等于/小于角色

【意象体系】
  视觉母题：贯穿全片反复出现的视觉元素
  意象方向：与主题/角色弧光呼应的环境意象风格
  需要突出强化的视觉元素：哪些物件/空间/动作在全片中有特殊分量
```

## 五、节奏规划与镜头组

### 双轨节奏

- **编剧阶段**已定：每场情节密度（松/中/紧）、情感分量（轻/中/重）、全片波浪图走向
- **导演阶段**要定：镜头密度、景别重心、时长分配、转场策略、**镜头组划分**

### 镜头组（Shot Group）

> 服务于同一个叙事目的的连续镜头序列。比"场景"小，比"单镜头"大。拆散就失去意义。

四种类型：

| 类型 | 特征 | 典型用途 |
|---|---|---|
| **蒙太奇组** | 多个并列画面快切，每镜 1-3 秒 | 建立氛围、展示规模、压缩时间 |
| **递进组** | 层层递进，每镜在上镜基础上增加信息或强化情绪 | 角色介绍、设定展示、情绪升级 |
| **因果组** | 动作→反应的因果关系 | 对话正反打、动作场景攻防 |
| **对比组** | 两个或多个画面形成对比 | 前后呼应、并行叙事、反讽 |

标注格式：
```
【场景2：邮局 / 白天】
  情节节奏：中（角色介绍）
  情感节奏：轻（轻松的铺垫）
  镜头组划分：
    组A"人物名片"（递进组，3-4镜，~6秒）
    组B"工作蒙太奇"（蒙太奇组，4-5镜，~8秒）
```

## 六、镜头设计（内部武器库）

### 动作-反应：基本单元

> **一个动作（行为）镜头（组）+ 一个反应（结果）镜头（组）**

"动作" = 任何引发变化的事件（一句台词、一个行为、一个信息）
"反应" = 事件对世界产生的影响（另一个角色的表情、环境变化、沉默本身）

### 十二种组合变体

| 变体 | 结构 | 效果 |
|---|---|---|
| 标准型 | 动作→反应 | 因果清晰，常规叙事主力 |
| **反应前置型** | 反应→动作 | 制造悬念（先看结果再看原因） |
| 动作并置型 | A→B→C→反应 | 累积压力，反应重量被放大 |
| **反应省略型** | 动作→（无反应）→下一场景 | 留白；观众脑补的反应比画面更强 |
| **动作隐藏型** | （声音动作）→视觉反应 | 声画分离，想象填充画面 |
| 反应延迟型 | 动作→日常→日常→反应 | 真实感（人消化冲击需要时间） |
| 同步型 | 动作与反应同画面 | 观众自选看谁，信息密度高 |
| 反应链型 | 动作→反应A→B→C | 展示事件辐射范围与不同态度 |
| 重复动作渐变型 | 同一动作（微变）→不同反应 | 通过变奏展示时间推移与情绪累积 |
| 对位型 | 画面动作A + 声音动作B → 复合反应 | 揭示表面与内在的矛盾 |
| 省略动作型 | 反应→反应→反应（动作从未出现） | 让"那件事"超越画面能承载的范围 |
| **链式衔接型** | 反应A兼动作B→反应B兼动作C | 多米诺骨牌，制造不可阻挡的叙事惯性 |

### 70/30 法则（出彩设计的配比与用量上限）

**70% 常规模式（撑骨架）**：标准型 ~30%、动作并置型 ~15%、递进组 ~15%、链式衔接型 ~10%

**30% 出彩模式（做记忆点）**：

| 出彩型 | 占比 | 用量上限 |
|---|---|---|
| 反应省略型 | ~5% | **一部短片用 1-2 次就够，用多了是偷懒** |
| 动作隐藏型 | ~5% | 需要声画分离制造张力时 |
| 反应前置型 | ~5% | 开场、反转段落 |
| 对比并置型 | ~5% | 需要视觉评论的段落 |
| 视觉奇观终极反应 | ~3% | **一部片子只用 1-2 次，没有铺垫的奇观只是特效** |
| 首尾闭环型 | ~2% | **只用 1 次**（结尾的反应精确回扣开头的动作） |

**选择逻辑**：先问"这里需要出彩吗？"（叙事重心 → 用 30% 模式）；再问"出彩用在刀刃上了吗？"
（一场戏已有一个出彩设计，剩下用常规模式托底）。**出彩模式的稀缺性就是它的力量。**

### 切镜连接逻辑（实测数据）

- **相邻景别平滑过渡**：约 **60%** 的切镜在一级景别跳幅内完成（全景→中景、中景→特写）
- **跨级跳切**：全景直接跳特写（或反向）产生强烈冲击，**约 15%**，都出现在叙事重要节点
- **同景别连续**：连续 3 个以上同景别会制造稳定/平静/压抑感；**超过 4 个需警惕单调**

## 七、九列分镜表规范

| 列名 | 说明 | 示例 |
|---|---|---|
| **镜号** | 从 1 开始连续编号；同镜多句对白分行时只在首行填镜号 | 1, 2, 3…；最后一镜标"结束" |
| **时长** | `MM:SS-MM:SS`；起始 = 上一镜结束时间；最后一镜 `MM:SS-结束` | 00:00-00:03 |
| **摄影角度** | 只用标准词：平视/平拍、俯拍、微俯拍、仰拍、极高俯拍、低机位 | 微俯拍 |
| **景别** | 大全景/远景 → 全景 → 中远景 → 中景 → 中近景 → 近景 → 特写 → 大特写/微距 | 特写转全景 |
| **画面内容** | **最核心列**。只写摄影机拍得到的：物理动作、环境关键元素、画面内文字、视觉特效。**用动作句不用状态句**（"老王推开门"而非"老王站在门口"） | |
| **场景** | 空间类型+具体位置；同一镜内空间变化要标注；抽象空间标"抽象空间" | |
| **声音** | 分类填：对白 `角色："台词"` / 旁白 / 配乐（风格+功能）/ 音效（具体声音）/ 静默 | |
| **备注** | **不需要每镜都填**。只在拍摄方式偏离默认时才标：镜头运动、特效、字幕、焦点转换、速度、滤镜、构图说明 | |
| **叙事目的** | 一句话覆盖结构功能 + 导演意图，具体到视听手段，不用心理描写 | |

### 时长估算基准（基于 **9 部短片 551 个有效镜头**实测）

**整体基准（短片）**：平均 **4.2 秒/镜**，中位数 **3 秒**，**76% 的镜头在 1-5 秒**

**按叙事目的类型**：

| 叙事目的 | 短片基准 |
|---|---|
| 推进/升级 | 2.5-3.5 秒（最快——事件在加速，镜头也加速） |
| 交代/建立 | 4-5 秒（需要让观众看清信息） |
| 展现/呈现 | 4-5 秒 |
| 情绪/氛围 | 4-5 秒（需要给氛围"呼吸"的时间） |
| 呼应/闭环 | 4-5 秒 |
| 转折/翻转 | 5-7 秒（需要足够时间让翻转的重量落地） |
| 升华/主旨 | 6-10 秒（最慢——终极意象需要停留和沉淀） |

**按内容表达量**（读取一层信息 ≈ 2-3 秒，每多一层加 2-3 秒）：

| 内容表达量 | 基准 | 典型场景 |
|---|---|---|
| 单一信息 | 2-3 秒 | 一个物件特写、一个简单动作 |
| 双重信息 | 4-5 秒 | 一个动作+环境关系、一句台词+反应 |
| 多层信息 | 6-8 秒 | 复杂场面、多人互动 |
| 综合段落 | 10-15 秒 | 长镜头调度、景别转换镜头、情绪留白 |

**按景别**：特写 2-4s / 中景 3-5s / 全景 4-5s / 远景 5-7s / 景别转换镜头 8-12s

**按镜头组**：快切蒙太奇组 3-14镜 共 6-20秒（1-2s/镜）/ 递进介绍组 3-5镜 共 6-12秒 /
标准叙事组 2-4镜 共 8-16秒 / 情绪留白组 1-3镜 共 8-20秒（5-15s/镜）

### 台词对时长的影响

> 台词长度影响镜头时长，但**语速不是固定值**——受角色性格、年龄、情绪状态、场景节奏综合影响。
> 同样一句 10 字台词：急躁的年轻人在争吵中说出来约 1.5 秒；沉稳的老人在回忆中可能需要 5 秒
> （中间有停顿、呼吸、沉默）；醉酒的含混角色可能 4 秒。
>
> **估算时应在脑中"演"一遍这句台词**——用这个角色在这个情境下的语速、停顿和呼吸去读。
> 台词时间之外，还要加上**反应时间**（对方听完后的停顿、表情变化）。

### 镜头数量参考

| 成片时长 | 镜头数 | 平均每镜 |
|---|---|---|
| 2-3 分钟 | 25-55 镜 | 3-5 秒 |
| 3-5 分钟 | 45-90 镜 | 3-5 秒 |
| 5-7 分钟 | 85-105 镜 | 3-5 秒 |

### 粒度：一个镜头一行

**算新镜号**：硬切到新画面、叠化/淡入淡出后的新画面、跳切
**不算新镜号**：镜头内推拉摇移、焦点转换、同镜内角色进出画

**通用上限**：单镜或单组尽量 ≤ **15 秒**。超过 15 秒必须有明确节奏意图，且镜头内部必须有视觉变化。

## 八、与下游（即梦提示词）的接口

山音方法产出的是**九列分镜表**，下一步要变成 AI 提示词，映射关系：

| 九列分镜表 | → 即梦提示词 10 区块 |
|---|---|
| 镜号 / 时长 | 决定**每个任务装几镜、总时长**（AI 单任务 4-15 秒，所以 3-5 镜要合并成一个任务） |
| 摄影角度 / 景别 | 写进【画面内容】的动作描述 + 【镜头】的全局约束 |
| 画面内容 | 【画面内容】的主体（只写可见动作） |
| 场景 | 【参考】里的场景素材 + "只取材质光线"说明 |
| 声音 | 【设定】（有无台词）+【限定】（禁止加音乐/音效） |
| 备注 | 【镜头】（运镜、焦点、速度） |
| **叙事目的** | **不直接进提示词**，但决定这一段的情绪与镜头选择 |

**关键换算**：分镜表按"cut"计算（一镜一行），AI 生成按"任务"计算（一个任务 4-15 秒、可含多镜）。
所以 60 秒短片 ≈ 15 个 cut ≈ **6-10 个生成任务**（每个任务 2-3 个 cut）。
