# 10 区块结构（剧情 TVC 剧本式）

> 来源：用户提供的 4 段即梦短剧实战范本归纳 + 本次建发短剧项目 5 轮迭代验证。
> 这套结构不是官方 5 模板的替代，而是**叙事层**的写法：它管「一场戏怎么讲清楚」，
> 官方模板管「一个任务内怎么切分」。两者可叠加使用。

## 总览

```
【风格】        一句话影调定调 + 超写实            ← 常量
【布光锁定】    整段英文，8 维度锁死视觉           ← 逐字复制（换项目只改 3 处）
【参考】        素材点名：角色 / 音色 / 场景 / 比例  ← 变量
【设定】        语言 + 表演基调（克制 vs 夸张）      ← 常量
【特殊要求】    背景人物策略（私密清空 / 公共克制）   ← 半常量
【导演】        身份锚定                            ← 常量
【故事背景】    谁·在哪·做什么，一句话              ← 变量
【画面内容】    动作流 + 台词流（本段主体）          ← 变量（核心）
【镜头】        机位 / 运镜 / 景别 / 正脸策略        ← 常量
【一致性】      面孔 / 服装 / 道具 / 空间 / 光源锁定  ← 常量
【限定】        4 条负向禁止                        ← 常量
```

**常量块占全文约 40%**，每段真正要新写的只有 `【参考】` + `【画面内容】`（+ 可选 `【特殊要求】`）。
这就是这套写法高效的原因：写作者只需专注「这场戏怎么演」。

---

## 【风格】

一句话影调定调，末尾加「超写实」。

- ✅ `现代东方雅致生活方式电影风格，超写实。`
- ✅ `日系青春氛围电影风格，超写实。`
- ❌ `高大上、有质感、电影感` —— 抽象词模型无法执行

## 【布光锁定】

一整段英文，按 8 个维度锁死视觉。4 段范本里**逐字相同**，是可复用的模板资产。

详见 `lighting-modules.md`（三套现成模块 + 换项目时的改法）。

**关键**：这一段是「视觉指纹」，全片必须同一条。不同任务各写一套，跨段必然像两部片子。

## 【参考】

按**角色**点名，不写「参考图片N」的模糊说法。素材顺序决定编号。

```
【参考】爸爸参考图片2，爸爸音色参考音频1；妈妈参考图片3，妈妈音色参考音频2；
       孩子参考图片4，孩子音色参考音频3；场景参考图片1，只取其材质与光线，
       不作全景背景，不迁移其中任何人物。
```

规则：
1. **角色在前，场景在后**（范本惯例）
2. **场景写清「只取什么、不取什么」**——这是防止场景图被当背景板的关键
3. 同框任务追加比例参考：`图片5为三人同框的身材比例参考，只取身高与体态比例，不迁移其中的服装与背景`
4. **不写任何改写角色卡的描述**（如「改为赤足」「穿平底鞋」）——卡是基准，提示词不改写它

## 【设定】

语言 + 表演基调，一句话。

- ✅ `画面中所有人都说标准普通话。人物说话要自然有情绪，不夸张表演。`
- ✅ 无台词段落写 `本段无台词，只有划水声、水声与远处隐约的笑声。`
- ❌ 长篇描述角色性格（模型执行不了）

## 【特殊要求】

背景人物策略，**按场景分层**（详见 `practice-notes.md` 的「背景人物」节）：

- **私密空间（家里）**：绝对无人。「这里是自己家里，除了一家人绝对不可能有其他人」
- **公共空间（会所/泳池/乐园/球馆）**：允许 1–3 位住户作中后景虚化背景，不直视镜头、不与主角互动、不遮挡主角，穿着得体、举止安静

反面教训：日系范本的「场景中有形形色色的人……请随机生成」是青春片要的群演感，
**搬到商业片会让背景人物抢戏，甚至把「一两位会员」画成孩子**。必须按场景重写。

## 【导演】

身份锚定，一句话。

- `你是一名顶级商业地产生活方式广告导演`
- `你是一名顶级日系青春氛围电影导演`

## 【故事背景】

谁·在哪·做什么，一句话，不写前因后果。

- ✅ `爸爸在恒温泳池游泳，妈妈带孩子从池边经过。`

## 【画面内容】—— 本段核心

**只写动作流 + 台词流**，技术描述（景别/机位/焦段/切镜）全部移到【镜头】。

写法公式：

```
角色名 + [动作/表情] + [视线对象] + [语气] + 说/喊/问：“台词”
```

例：
```
孩子停下脚步，转头看向水里，抬起手朝爸爸挥，冲着爸爸喊：“爸爸！我们去玩啦！”
```

**四条铁律**（详见 `practice-notes.md`）：
1. 每句台词必须有**说话对象**
2. 每句台词必须有**视线方向**
3. 台词与动作的**先后顺序**必须合乎因果（先说要、再给；不能先接过再说给我）
4. 台词不能**回答一个没人问过的问题**

**动线逻辑**：写清每个角色从哪到哪、朝哪个方向走。分开就当场道别，不要分开了又跑回来道别。

**镜头提示用括号放末尾**（照范本写法）：
```
……三人一起笑起来。（最后镜头停在三人的中景上保持不动，约两秒，不拉远、不切走。）
```

## 【镜头】

机位、运镜、景别策略、正脸策略，**常量块**。

```
【镜头】稳定机位与极缓慢推轨。自然切镜。全片不使用大全景、远景或全景，最远到中景；
场景只以材质、光斑、家具或结构局部出现在人物身后，不作为整幅背景使用；
优先拍反应、背影、侧影与手部，不连续给正面平视，避免证件照式的正面交代。
```

可调项：
- 运动方式（稳定 / 手持 / 环绕）——决定片子的性格
- 景别上限（全片最远到哪）——决定片子的"距离感"
- 正脸策略——AI 生成的脸最容易崩，正面镜头越少越安全
- 前景虚化——**谨慎**：用多了像偷窥，不是电影感

## 【一致性】

防漂移的集中约束段（官方范本没有，是本技能补的缺口）：

```
【一致性】三人保持各自同一面孔、发型与服装；身形比例稳定，不出现换脸、多手、
手指融合、肢体变形或穿模；空间方向恒定，标志物相对位置不变；同一任务内光源方向不跳变；
禁止字幕、禁止新增文字与标识。
```

按需追加：
- 道具数量锁（球拍、钥匙等）：「每只手最多握一只，绝不出现第三只或残影」
- 角色唯一性锁：「画面中只有一个孩子，绝不出现第二个儿童形象」
- 背景人物约束：「只作为虚化背景，始终保持中后景」
- 场景文字保护：「墙面既有文字是场景特征，保持原样，不新增、不改写、不抹除」

## 【限定】

四条负向禁止，逐字复制：

```
【限定】禁止加音乐，禁止加文字和标注。禁止加音效。禁止改变人物台词顺序。
```

四条各防一种模型自作主张：
1. 禁止加音乐 —— 防止自动配 BGM（后期统一配）
2. 禁止加文字和标注 —— 防止字幕/贴纸/水印
3. 禁止加音效 —— 防止夸张音效（与布光段的「只留环境声」配合读）
4. 禁止改变人物台词顺序 —— 防改编、漏句、乱序

## 完整示例（7 秒泳池段）

```
【风格】现代东方雅致生活方式电影风格，超写实。
【布光锁定】<英文 8 维度，见 lighting-modules.md 模块 B>
【参考】爸爸参考图片2；爸爸音色参考音频1；妈妈参考图片3；孩子参考图片4，孩子音色参考音频2；
       场景参考图片1，只取其材质与光线，不作全景背景，不迁移其中任何人物。
【设定】本段无台词，只有划水声、水声与远处隐约的笑声。
【特殊要求】这是高净值住区的会所……允许出现少量其他住户作为背景——远端泳道有一两位泳客
           在缓慢游动，池边躺椅上有一位住户在休息看手机；背景人物中后景虚化，不直视镜头、
           不与主角互动、不遮挡主角，每场景 1-3 位；主角始终是唯一视觉重心。
【导演】你是一名顶级商业地产生活方式广告导演
【故事背景】：爸爸在恒温泳池游泳，妈妈带孩子从池边经过。
【画面内容】（先是水面的空镜：天花灯带在水面上晃出光斑，水波轻轻荡开）
           爸爸从画面右侧游入，向前自由泳，肩背舒展，水花在肩侧翻起（从侧后方拍，不见正脸）。
           远处隐约传来孩子的笑声与水声。爸爸在水里停了一下，侧头望向声音传来的方向，笑了一下，
           继续向前游。
【镜头】稳定机位与极缓慢推轨。自然切镜。全片不使用大全景、远景或全景，最远到中景；……
【一致性】爸爸保持同一面孔与深藏青泳裤，妈妈保持日常优雅装与低盘发，孩子保持长发半扎与
           白衬衫米驼背带短裤；身形比例稳定，不出现换脸、多手、肢体变形或水面穿模；……
【限定】禁止加音乐，禁止加文字和标注。禁止加音效。禁止改变人物台词顺序。
```

## 常见错误对照

| 错误 | 现象 | 修正 |
|---|---|---|
| 技术词混进【画面内容】 | 写成「（中景）爸爸起身」 | 景别移进【镜头】，画面内容只留戏 |
| 场景当背景板 | 每段都从全景看整个空间 | 场景只取材质/光/局部，人占主体 |
| 台词没对象 | 「孩子对着水面喊」 | 写清看向谁、冲谁说 |
| 台词回答没人问的问题 | 妈妈一进门就说「不是来打球的」 | 先让孩子邀请，妈妈再回答 |
| 分开后又回来道别 | 大堂分开了，泳池又相遇道别 | 分开时一次把道别说完 |
| 角色卡被提示词改写 | 「妈妈改为赤足」 | 换卡，或不管；不改写卡 |
| 提示词含 Markdown | `**面朝窗**` | 清掉所有 `**`、`#` 等标记 |
