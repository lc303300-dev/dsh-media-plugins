# 实战补充（非社区项目内容）

> **来源**：本仓库「建发观澜短剧」项目（2026-10）实际制片过程中验证的经验。
> **定位**：这部分**不是**社区项目（山音导演大师）的原文，也**不是**用户提供的即梦范本规范，
> 而是本次项目踩坑后总结的补充经验。可按需采用，不作为权威依据。

## 一、三幕叙事结构

### 诊断：为什么像片段拼凑

商业短片最常见的失败：**8 段各拍一个空间/功能，每段都是完整小戏，但没有因果**。

判断方法只有一个：

> **把任意两段交换顺序，故事还成立吗？**

- 成立 → **并列展示**（宣传片：观众记住的是功能清单）
- 不成立 → **因果递进**（TVC：观众记住的是故事）

并列展示的典型症状：每段都「有人在做某件事」但不知为什么是这一段；每段都有独立小起承转合；
每段都在换地点且接缝没有动作/声音/方向延续；情绪是平的。

**根因不在生成，在结构**。AI 按段独立生成，段间天然没有状态传递——脚本层面并列，拼接必然碎片。

### 三幕骨架

```
Act 1 · Setup       引入常态 + 触发事件
Act 2 · Rising      挑战升级 / 递进 / 高潮（转折点必须显式存在）
Act 3 · Resolution  转折 + 情感落点
```

给每段标 `arc_position`（setup / rising / climax / resolution）和 `emotion`（用一句具体的话，
不是形容词）。**Act 2 必须有递进，不能是并列。**

### 实战案例：建发短剧 8 段重排

原始顺序（按空间）：`客厅 → 大堂 → 泳池 → 乐园 → 瑜伽 → 健身 → 书吧 → 乒乓`
问题：中间五段是功能展示，情绪是平的（爸爸玩 → 孩子玩 → 妈妈玩 → 爸爸孩子玩 → 妈妈看书）。

重排后（按情感逻辑）：

| # | 段 | 位置 | 一句话情绪 |
|---|---|---|---|
| 1 | 客厅 | setup | 各有各的周末计划，谁也不想跟谁玩 |
| 2 | 大堂 | rising / 分开 | 爸爸去泳池、妈妈带孩子去乐园 |
| 3 | 泳池 | rising / 各自 | 爸爸一个人游泳，水里只有他自己 |
| 4 | 瑜伽室 | rising / 各自 | 妈妈一个人舒展，终于静下来 |
| 5 | 乐园 | rising / 缺口 | 孩子在玩，但爸爸不在 |
| 6 | 健身房 | **climax / 转折** | **妈妈主动走过来看爸爸** ← 第一次靠近 |
| 7 | 书吧 | rising / 被吸引 | 妈妈刚坐下就被乒乓声牵走 |
| 8 | 乒乓 | resolution / 重聚 | 一家人笑在一起，后拉全家福 |

**关键洞察**：这五段自带情绪递进，只是原本按空间顺序排成了并列。按
「分开 → 各自 → 缺口 → 靠近 → 被吸引 → 重聚」重排，一条弧线就出来了。**不改内容，只改顺序。**

### 每段「存在理由」自检

对每段问：**删掉它，故事会缺什么？** 答不出来 → 这段是功能展示，应删或合并。

## 二、转场设计

### 核心原则

> **好的接缝至少保持「动作 / 方向 / 形状 / 视线 / 声音 / 光线」中的两项。**
> **避免同时无解释地改变地点、动作、景别、方向、服装和天气。**

### 六种可用手段

| 手段 | 怎么用 | 成本 |
|---|---|---|
| **声音桥**（J/L cut） | 下一段声音提前进入，或上一段声音延续 | 最低（后期即可） |
| **动作匹配** | 上段结尾动作在下一段开头以相同状态继续 | 中（两段都要配合） |
| **形状匹配** | 上段结尾图形/物件与下段开头相似 | 中 |
| **视线引导** | 上段角色看向画外 → 下段揭示他看的东西 | 中（最电影化） |
| **方向延续** | 上段往左走 → 下段继续往左/从左侧入画 | 低（写动线时就能定） |
| **光线延续** | 上段结尾光向、色温在下一段保持 | 低（布光模块统一即可） |

### 实战：8 段 7 个接缝

| 接缝 | 保持什么 | 做法 |
|---|---|---|
| 客厅 → 大堂 | 动作 + 方向 | 三人往门口走 → 三双脚跨门槛特写，镜头上摇进大堂 |
| 大堂 → 泳池 | 方向 + 动作 | 爸爸往左转身走向泳池 → 泳池水面开场 |
| 泳池 → 瑜伽室 | 声音 | 水声渐弱 → 吸气声起 |
| 瑜伽室 → 乐园 | 动作 + 光线 | 妈妈起身走向门口 → 门后暖光变成球池的光 |
| 乐园 → 健身房 | 声音 | 孩子的笑声延续到健身房 |
| 健身房 → 书吧 | 动作 + 方向 | 妈妈从门口离开 → 书吧长桌前坐下 |
| 书吧 → 乒乓 | 声音 | 乒乓声由远及近 |

### 声音桥三种写法

1. **提前进入（J cut）**：下段声音在上段最后 0.5 秒就出现
2. **延迟退出（L cut）**：上段声音延续到下段开头
3. **声音钩子**：A 段埋声音，C 段才解释（书吧段埋乒乓声 → 下段揭示）

### 后期必做三件事（不改素材）

1. **一条贯穿的音乐**——8 段环境声直接会碎；铺一条等长音乐，环境声压到 -12dB 以下
2. **片头标版**（2–3 秒）
3. **片尾落板**——品牌名 + slogan + 项目定帧

## 三、连续性与台词纪律

### 连续性六类状态

连续性不是「画面相似」，是**状态传递**：

| 类别 | 要传什么 |
|---|---|
| 身份 | 脸、发型、体型、标记、服装结构 |
| 空间 | 地点、轴线、屏幕方向、机位侧、主体位置 |
| 动作 | 接触阶段、速度、姿势、视线、意图 |
| 道具 | 数量、主人、朝向、开关、干湿、完好/损坏 |
| 环境 | 时间、天气、光向、地面、群众 |
| 声音 | 房间底噪、音乐乐句、当前对白与尾音 |

### 台词四条铁律

**1. 每句台词必须有说话对象**
- ❌ `孩子对着水面喊` → ✅ `孩子转头看向水里，抬起手朝爸爸挥，冲着爸爸喊`

**2. 每句台词必须有视线方向**
- ✅ `妈妈侧头看向爸爸，笑着说` / ❌ `妈妈头也没回地说`（确要「不看」须写明对谁说）

**3. 台词与动作顺序必须合乎因果**
- ❌ `妈妈伸手接过球拍，说：「给我一个球拍！」`（已接过还要）
- ✅ `妈妈：「给我一个球拍！」→ 孩子把球拍递给她 → 妈妈接过`

**4. 台词不能回答一个没人问过的问题**
- ❌ 妈妈一进门就说「不是来打球的，我是来叫你们回家的」（谁问她要不要打球？）
- ✅ 孩子先邀请「妈妈！那你陪我们打一局嘛！」→ 妈妈答「不是来打球的，我是来叫你们回家的」

**第 4 条最隐蔽**：读起来没错，但观众会隐约觉得假，因为缺少提问者。

### 动线逻辑

**分开就当场道别，不要分开了又回来道别**

- ❌ 大堂分开（爸爸去泳池）→ 泳池段妈妈又带孩子经过池边道别
- ✅ 大堂分开时一次说完：「孩子回头冲爸爸喊：爸爸！我们去玩啦！爸爸也回头挥手：好！等会儿找你们！」

**孩子监护**（孩子始终需要至少一个家长陪伴）：

| 段 | 爸爸 | 妈妈 | 孩子在谁身边 |
|---|---|---|---|
| 客厅 | 在家 | 在家 | 父母都在 |
| 大堂 | 去泳池 | 带孩子 | 妈妈 |
| 泳池 | 游泳 | 带孩子池边 | 妈妈 |
| 乐园 | 游完过来 | 拍照 | 妈妈 → 交给爸爸 |
| **瑜伽室** | 带孩子（**需交代**） | 独自瑜伽 | ⚠️ 用画外声音补：「画外传来孩子的笑声和爸爸说话的声音」 |
| 健身房 | 跑步 | 从门口来 | 爸爸 |
| **书吧** | 带孩子打球（**需交代**） | 看书 | ⚠️ 写实：「远处传来孩子的笑声与乒乓声——那是爸爸正带着孩子在球馆打球」 |
| 乒乓 | 打球 | 来找 | 爸爸 |

**画外声音交代优于加人物入画**：省成本，也不破坏单人段的安静感。

**站位必须写清**（球台/桌面这类有方位的场景）：
- ❌ `爸爸在左侧、孩子在右侧`（可以是并排同一侧）
- ✅ `爸爸站在球台的一端，孩子站在球台的另一端，两人隔着球网面对面站着对打（不是并排站在同一侧）`

### 反常识检查清单

| 检查项 | 反例 |
|---|---|
| 鞋履与场景 | 高跟鞋走在湿滑泳池边 |
| 服装与场景 | 长袖厚衣在泳池；礼服在健身房 |
| 道具状态 | 游泳时身上挂毛巾；接过球拍后说「给我一个球拍」 |
| 动作物理 | 自由泳时转头挥手；跑步机朝窗但人朝室内 |
| 位置关系 | 孩子扒球台高度不对；妈妈从「叫回家」到「加入」缺少铺垫 |
| 时间逻辑 | 分两段道别；分开后又相遇 |

**角色卡纪律（最重要）**：卡上的东西就是基准，**提示词不改写卡**（不改鞋、不改服装、不改发型）。
与场景冲突时只有两条路：**换卡**（同角色不同服装套）或**补卡**（新出场景适配卡）。
唯一例外是**道具状态**：泳装卡的毛巾可规定为「岸上道具、不随人物入水」——这不是改写卡，是规定物理状态。

### 背景人物策略（按场景分层）

| 场景类型 | 策略 | 理由 |
|---|---|---|
| **私密**（家里） | **绝对无人** | 自己家出现陌生人不合理 |
| **公共**（会所/泳池/乐园/球馆） | **1–3 位住户，中后景虚化，不抢戏** | 生活气息来自「有人真的在这里生活」 |

公共场景三条硬约束：中后景不遮挡主角 / 各有其事不直视镜头不互动 / 穿着得体举止安静。

**踩过的坑**：写「一两位会员」没限定成年，AI 画成了孩子 → 画面出现两个小女孩。
正确写法：「**成年**会员（必须成年人，不能是孩子或青少年）」+【一致性】加「画面中只有一个孩子」。

### 提交前必查的三个「污染」

| 污染 | 现象 | 处理 |
|---|---|---|
| **Markdown 标记** | 提示词混进 `**加粗**`、`#`、`- ` | 提交前扫 `**` 并清除 |
| **未替换的占位编号** | 残留 `图片1` / `音频2` | 提交前正则检查 |
| **参考图文件名泄漏** | 正文出现 `.png` / `.mp4` | 只允许节点引用，不写文件名 |

### 前景虚化的用量纪律

`soft foreground occlusion` 用多了会变成「偷窥视角」，不是电影感。
真正需要它的只有四种情形：**建立旁观视角 / 框式转场 / 遮挡次要信息 / 制造纵深**。
全片 8 段用 5 次已经是上限，其余段落保持干净构图。
