# 短剧模式

## 进入动作（每次进入只做这三件）

1. **第一句宣告**：`已进入短剧模式。` 后面直接给能力目录，不要先寒暄。
2. **报能力目录**（下面第二节那张表，原样给出，让用户点菜）。
3. **只问必要信息**：一次最多问 3 个，能从已有文件读到的绝不问。

> 短剧是**解耦能力集**，不是 7 步流水线。用户说「先做角色卡」就只做角色卡，说「分镜表转提示词」就直接进提示词阶段——**不要因为缺前置就强迫他从第 0 步开始**，只提示缺什么、可以怎么补。

## 能力目录

### 素材层（可独立、可并行、可缺省）

| 能力 | 触发说法 | 输入 | 产出 | 依赖 |
|---|---|---|---|---|
| 角色卡 | 做角色卡 / 人物卡 | 人物照片 | 3:4 标准角色卡（走已发布图片 Skill `character-card-template`） | 无 |
| 场景卡 | 做场景卡 / 场景设定 | 实景照片、地点信息 | 16:9 场景卡（地点真实名称必须写进提示词；**不带人物**） | 无 |
| 道具卡 | 做道具卡 | 道具照片 | 1:1 道具设定 | 无 |
| 音色 | 做音色 / 声音模板 | 角色 + 基准台词 | 每人一段音色样本 | 角色卡 |

**素材纪律**：素材是**参考**不是构图命令——只提供材质、色彩、光线、人物长相，不提供景别与构图（见 `video-director-prompt/references/ai-video-shooting-rules.md` 第一节）；场景卡**不带人物**、必须写真实地点名、文字两头都不管（既不写"禁止出现文字"，也不强制"必须写出某某招牌字"）。

**素材生图的 provider 分线（硬规则，2026-11-06 定）**：

| 素材类型 | 判定 | 线路 |
|---|---|---|
| 角色卡 · 真人 | 卡面是照片本人的**写实**呈现 | `image_provider = comfly-gemini-flash-preview` |
| 角色卡 · 风格化 | 插画 / 国潮 / 手绘动画 / 二次元 / 漫画等**非写实**形象 | `image_provider = comfly-gpt-image-2-4k` |

- 判定只看「卡面是不是真人写实」：是 → Gemini，不是 → GPT。**风格化角色直接走 GPT，不要问**，也不要因为"角色卡默认走 Gemini"而落到 Gemini 线。
- 接入参考图优先用 `batch_image` 的 `reference_images`（`generate_image` 的 `image` 通道在本机曾报 `image must be an array`）。
- 场景卡 / 道具卡不涉及人脸写实判定，走默认线路即可。

### 脚本层（六个能力，各自独立触发，不强制顺序）

| 能力 | 触发说法 | 输入 | 产出 | 依赖 |
|---|---|---|---|---|
| 诊断 | 诊断大纲 / 拆信息点 / 核时长 | 客户大纲（docx/md/文本） | `00-诊断报告.md`：信息点清单 + 四类问题 + 时长核算 | 无 |
| 台词定稿 | 台词定稿 / 改台词 / 台词口语化 | 信息点清单 | `01-台词定稿.md`：逐句定稿 + 信息点 N/N 核对 | 诊断（信息点） |
| 导演脚本 | 写分镜 / 九列分镜表 / 导演脚本 | 台词定稿（或大纲） | `00-导演骨架.md`：定调 + 节奏 + 九列分镜表 + 任务划分 + 12 项自检 | 台词（或直接大纲） |
| 执行脚本 | 执行脚本 / 台词素材映射 / 任务划分 | 九列分镜表 + 素材清单 | `01-执行脚本-正式版.md`（六章 + **任务级硬约束表**） | 导演脚本 + 素材 |
| 通用提示词包 | 通用提示词包 / 布光锁定 / 常量块 | 项目定位 + 参考图 | `30-通用提示词包.md`：7 个常量块全文 | 无（布光需图） |
| 即梦提示词 | 即梦短剧提示词 / 10 区块 / 逐镜行 | 执行脚本 + 通用提示词包 + 素材 | `02-即梦提示词-可提交版.md` + 校验报告 | 执行脚本 + 通用提示词包 |

### 执行层

| 能力 | 触发说法 | 输入 | 产出 | 依赖 |
|---|---|---|---|---|
| 画板交付 | 上画板 / 建节点 / 交付 | 可提交提示词 + 素材 | 画布图片节点 + 视频节点（不自动开始）；docx/文件清单 | 即梦提示词 |

## 依赖关系（是「输入条件」，不是「必须走的顺序」）

```
[角色卡/场景卡/道具卡/音色] ──┐
                              ├─→ 执行脚本 ──→ 即梦提示词 ──→ 画板交付
诊断 ─→ 台词定稿 ─→ 导演脚本 ─┘
                         └─→ 通用提示词包 ──┘
```

- 用户只给大纲、要一条龙：按依赖顺序走，但**每步产出先给用户看**，不要连跑。
- 用户只给执行脚本、要提示词：跳过前面，直接进 `drama-prompt`，只校验执行脚本是否含「任务级硬约束表」。
- 用户只要改一段：只动对应能力，不重跑全链。

## 模式纪律（硬规则，进入模式后一直生效）

1. **口径**：Gemini 只做两样——① 导演脚本（小说体，按大纲写）；② 布光／风格锁定（看图写整体锁 + 分时段模块）。**执行脚本与即梦提示词由 Agent 自己写**（任务分组、11 区块装配、画面内容、逐镜行），不调用 `creative_writer`（2026-11-10 定）。
2. **分组在执行脚本定死**：一个「生成任务」＝后面一个视频节点 / 一段提示词，分组、镜数、开场景别、切换桥都在执行脚本层确定；**提示词层只按组改写，不得重新分组、不得增删镜**（`three-script-workflow.md`）。
3. **规则硬化，不靠自觉**：
   - 每任务 2–5 镜、4–15 秒、景别数按导演脚本成立；
   - **切换场景卡后的第一镜必须是特写**（脚本型开场例外见 `ai-video-shooting-rules.md` 第十一节）；
   - 同一场景卡、时空连续的散镜必须合进同一任务；
   - 这些字段写进执行脚本的「任务级硬约束表」，并由 `check_exec_script.py` 机械校验。
4. **提示词层机械校验必跑**：`check_prompts.py`（镜数 / 时间戳闭环 / 10 区块 / `图片N` 绑定 / 开场景别）。
5. **提交门走豁免**：`prompt_batch set_prompts` / `generate_video` 仍会校验 24h 内 `creative_writer` 记录；按新分工提示词由 Agent 写，提交时必须传 `allow_manual_prompts: true` + `manual_prompts_reason: "2026-11-10 分工：提示词层由 Agent 改写，Gemini 只做导演脚本与布光"`，留痕但不静默。
6. **不跳步、不静默**：每步产出先给用户看，拿到明确放行再走下一步；返工按 `guided-production-flow.md` 的 8 族词处理。
7. **素材是参考不是构图命令**；参考图不得 1:1 成画面（每个镜头重新架机位）。

## 与默认视频线的边界

| 场景 | 走哪条 |
|---|---|
| 用户说「进入短剧模式」/ 一条片子多段、要剧本→分镜→提示词→画板 | **本模式（短剧技能集）** |
| 单条视频、只要一个提示词 | `video-prompt-orchestrator` 默认线 |
| 多素材批次、逐段确认 | `video-prompt-orchestrator` 批次模式 |
| 业务 Skill 治理 / 发布 | `skill_curator` / `codex-cs-skill-curator` |

**进入短剧模式后，本轮对话不再落回默认线**，除非用户明确说「退出短剧模式」或要求只做单条提示词。
