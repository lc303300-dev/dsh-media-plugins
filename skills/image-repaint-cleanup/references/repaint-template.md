# 洗图模板全文 · 主模板 + 可插拔模块 + 实测经验

> 本文件是 `image-repaint-cleanup` 技能的详细参考，按需加载。
> 来源：2026-10 实测批次（浮空社区岛屿、黄鹤楼江景、现代书香门庭、WC 系列、日落湖畔、武汉天际线等）。
> **口径纪律**：上述批次集中在城市 / 江景 / 湖景 / 建筑题材，早期版本的 `M1` / `M2` / `M4` / `M5` 因此带有题材与时段偏向，已按"**以原图为唯一基准，不擅自换时段、不擅自换天**"的通用口径修订。新增实测经验时请写明**适用题材与时段**，不要写成全局默认。

## 〇、前置看图门（洗图第一步，不可跳过）

洗图会把"绘画化的人体错误"修成**更清晰**的畸变：插画里含糊的手指，写实化后变成明确的多指/粘连；涂抹的脸，写实化后变成崩坏的五官。所以**先看图，再决定挂哪些模块**。

**看图动作**（`describe_image` 已 disabled，用自身视觉看图）

1. `image_preview`（默认最长边 1024，非破坏、不覆盖原图）→ `read_image` 读预览图。
2. 逐张看，不许抽样。
3. 画面里手/脸占比很小时：用 PIL 裁切该 ROI → 放大到最长边 1024 → **另存新文件** → `read_image` 复核（原图不动）。
4. 批量（`batch_image`）也要逐张看完再提交；人物清单随提交说明一起给用户。
5. **自然产物与透明材质也逐项过一遍**（这是与人物并列的第二大类易损区）：水（水面 / 波纹 / 倒影 / 水花）→ `M6-水`；植被（树冠 / 灌木 / 草地 / 花）→ `M6-植被`；树叶（叶簇 / 树叶特写 / 逆光叶片）→ `M6-树叶`；云与天空 → `M6-云朵`；地形 / 岩壁 / 沙土 / 雾霭 → `M6-地形与大气`；玻璃 / 幕墙 / 瓶罐 / 镜面 → `M10`。**逐一登记到位，宁多勿漏。**
6. **顺手登记风格需求**：用户给了**风格参考图**（要统一整体风格与色调）→ 记为图 2、定强度档（默认「中」）、挂 `M9`；同时比较各原图之间的色温与影调差异（差异越大越需要 M9 统一）。用户没给风格图就不要替他臆造风格。

**看图结论表（每张一行，交付时附上）**

| 文件 | 人物/角色/身体部位 | 景别与占比 | 风格 | 材质清单 | 第 4 段点名重建目标 | 挂载模块 |
|---|---|---|---|---|---|---|
| 例：a.png | 1 名女性角色（站立全身）+ 远景 2 行人 | 主体 45% / 远景 3% | 半写实插画 | 织物、皮革、金属扣、玻璃 | 面部五官、手指、发丝、服装褶皱、幕墙窗格 | 主模板 + M8 + M8-远景精简句 + M3 + M9(中，图2 风格参考) |

**判定与挂载（照做，不要靠感觉）**

| 看图发现 | 判定 | 必挂 |
|---|---|---|
| 完全没有人物 / 人体 / 雕像 / 拟人动物 | 无人 | 主模板 5 段 + `M2`（天空保真）；`M1` 仅原图本身是黄昏或用户明确要求推浓时挂，其余模块按需 |
| 远景剪影级小人（占画面高度 <5%） | 远景小人 | `M7` + `M8-远景精简句` |
| 脸部可辨，或人物占画面高度 ≥10% | 近景人物 | **`M8` 完整版** |
| 只有局部部位特写（手 / 脸 / 腿 / 脚） | 部位特写 | **`M8` 完整版 + `M8-局部特写`** |
| 群像 / 人群 / 合影 | 群体 | **`M8` 完整版** + 数量、排列、前后遮挡关系锁定 |
| 雕像 / 人体模型 / 玩偶 / 机甲等人形物体 | 非真人 | `M8`（皮肤条款改成按实际材质写：石材 / 金属 / 塑料 / 陶瓷），**不得洗成真人皮肤** |
| 拟人动物 / 兽人 / 吉祥物 | 混合体 | `M8` + 对应动物解剖条款（耳、吻、爪、尾、毛 / 鳞） |
| 卡通 / 二次元 / 风格化角色 | 风格化 | `M8` + **`M8-风格化条款`**（保风格化面部比例与配色，禁止写实真人化） |
| 只剩影子 / 局部被遮挡 / 被画面裁切 | 局部 | 至少挂 `M8-远景精简句`，并明确"不补全、不新增肢体与人物" |
| 有水（水面 / 波纹 / 倒影 / 水花 / 雨雪水汽） | 自然-水 | `M6-水`（另有雾霭再加 `M6-地形与大气`） |
| 有植被 / 草地 / 花丛 / 藤蔓 / 树皮 | 自然-植物 | `M6-植被` |
| 有树叶（叶簇 / 前景叶 / 逆光叶片 / 树叶特写） | 自然-叶 | `M6-树叶`（与 `M6-植被` 同挂） |
| 有云 / 天空主导 | 自然-云 | `M6-云朵` + `M2`；**仅当原图本身就是黄昏、或用户明确要求推浓氛围**时再叠 `M1` |
| 有地形 / 岩壁 / 沙土 / 雾霭大气 | 自然-地景 | `M6-地形与大气` |
| 有玻璃 / 幕墙 / 窗 / 瓶罐 / 镜面 / 亚克力 | 透明材质 | `M10` |

**拿不准就挂**：不确定画面里那是不是人形，宁可挂 `M8-远景精简句`（只锁数量位置）也不要漏；漏挂的代价是畸变被放大，挂多的代价只是多几十字。

**风格统一由用户决定**：只有用户给了**风格参考图**才挂 `M9`（强度默认「中」）；用户没给就不要自行指定风格，也不要把某张原图当成风格基准去统一别的图——那会变成"擅自换风格"。

## 一、主模板（核心五段，直接复制）

```
【1 基准声明】
以输入图片为严格的构图与设计参考，将整个画面重新渲染为 Unreal Engine 5 风格的高品质写实 CG。

【2 必须保持】
保持原图的机位、透视、构图、主体身份、姿态、轮廓、物体比例、位置、配色及主要光源方向；
保持原图的 {{时段与光色，例：金色夕阳黄昏光色、暖调天空与水汽氛围}} 不变。

【3 重建（写实化）】
重新构建清晰可信的三维体积、表面材质和光照：使用物理合理的 PBR 材质，准确区分
{{材质清单，例：金属、玻璃、石材、混凝土、木材、织物、水与植被}} 的粗糙度、反射和透光特性。
呈现自然的间接光、接触阴影、合理的反射和连续的明暗过渡。

【4 去绘画感】
去除原图的绘画笔触、涂抹感、碎裂纹理和无意义的高频细节；将这些区域重建为符合物体结构的几何细节与材质纹理
（{{逐项点名重建目标}}）。

【5 负面与出口】
整体呈现干净、精细的电影级写实 CG，避免塑料感、玩具质感、过度锐化和随机新增细节；
不要改变 {{不可变结构清单}}，不要新增或删除元素。
```

第 4 段的 `{{逐项点名重建目标}}` 按**本图实际内容**挑（没有的对象不要写）：树冠呈现可信的枝叶体积与透光；云层呈现自然的云体结构；水面呈现真实的波纹与倒影；楼体幕墙分割与窗格清晰可信；石材出现纹理与接缝；金属呈现正确的反射；玻璃保持通透与室内暖光透出；**人物 → 面部五官与手指结构、发丝体积、皮肤质感、服装织物褶皱；产品 → 本体材质、边角圆角与标识**。

## 二、可插拔模块（按需附加）

### M1 · 黄金时刻氛围（**默认不挂**）

> **挂载条件（两条满足其一才挂）**：① 看图确认**原图本身就是黄昏 / 黄金时刻**；或 ② 用户明确要求"氛围再浓一点 / 更黄昏一些"。
> **原图不是黄昏就绝不挂 M1**——那等于擅自换时段，违反主模板第 2 段"保持原图时段与光色不变"。
> 本模块**只加强原图已有的光色**：**不新增太阳 / 日轮，不改变日轮的位置、大小与高度**；原图没有可见日轮就不要让它出现。

```
· 保持原图时段、太阳高度与机位不变，只加强已有的黄金时刻光色：
  受光面铺一层暖金，阴影加长并保持中性或略偏冷，形成明确的冷暖对比。
· 天空与云层只加强原图已有的暖色与受光 / 背光层次（云的受光面金橙、背光面偏灰蓝）；
  云的形状、数量与分布不变，**不新增日轮、不改动日轮位置与太阳高度**。
· 水面、玻璃、金属出现朝太阳方向的金色反光带与高光。
```

### M2 · 天空保真（防"模型擅自换天"，昼夜通用，**天空一律挂**）

```
天空严格沿用原图的天色、云量与云型，只做质感强化（去噪、去涂抹、真实大气散射），不改时段、不改色相：
· 原图是阴天 / 多云 / 雾霾 / 暮色，就保持阴天 / 多云 / 雾霾 / 暮色，不得擅自换成艳蓝晴空或通透蓝天；
· 原图是蓝天，就保留蓝天与原有云量，不得擅自改成偏白少云，也不得刷成高饱和度假天空；
· 原图无云就保持无云，不得凭空添加白云、云海、霞光或日轮；
· 天色、云层结构与大气透视可以更真实，但时段与色相不得偏离原图。
```

### M3 · 固有色纪律（防"黄昏变全局黄染"，最常用）

```
· 严格保留物体固有色——白色/米白墙面仍是白与米白，混凝土与石材保持中性灰，
  金属保持本色，植被保持自然绿，水面保持通透。
· 严禁把黄色铺到整个画面：不要全局黄色雾霭，不要黄/橙色滤镜，不要整体色温偏移，
  不要把所有材质统一染成暖棕。
· 白平衡干净准确：画面中的白色区域在日光下仍应读作白色。
· 时段氛围（黄昏 / 暮色的暖光、夜景的灯色）只体现在天空与受光高光上，画面其余部分色彩干净。
```

### M4 · 主体过暗提亮（防逆光剪影）

> 占位符只按**本图实际主体**填写，不要把别的题材的词汇带进来（人物图不要写幕墙 / 层数，产品图不要写立面 / 开窗）。

```
图1 中 {{主体，例：建筑立面 / 人物与服装 / 产品本体 / 车辆 / 室内空间}} 被压成了近乎黑色的剪影——请把它提亮：
{{受光面与关键表面，例：建筑 → 浅色立面与材质本色清晰可读；人物 → 面部、肤色与服装层次可读；
产品 → 本体材质、边角与标识可读；室内 → 墙面、家具与结构线脚可读}}，
{{结构细节，例：护栏、竖向格栅、层间线脚 / 五官、发丝、服装褶皱 / 边角、分模线、按键}}恢复可见。
它是画面中{{主光关系，例：受夕阳照明的受光主体 / 逆光但应保持可读的主体}}，暗部允许存在但不得死黑。
不要改变它的造型、结构、比例、数量、位置与朝向。
禁止：不要逆光剪影、不要把主体压黑、不要让整体过暗或暗部死黑。主体提亮是本次最重要的修改点。
```

### M5 · 建筑 / 材料专项

```
高层建筑的体块、幕墙分割与窗格结构应清晰可信；石材保留清晰纹理与接缝；
金属呈现正确的反射；玻璃保持通透与室内暖光透出；木材保留纹理与漫反射。
```

### M6 · 自然产物专项（水 / 植被 / 树叶 / 云朵 / 地形与大气）

> 用法：看图发现哪一类就挂哪一类（可多个同挂），并把该类关键词**写进主模板第 4 段的点名清单**——只写"自然一点"模型会忽略。水面的反射/折射与玻璃是两套物理：水面用 `M6-水`，玻璃与镜面用 `M10`，两者可同挂。

**M6-水**

```
水呈现真实的液态质感：
· 波纹：有方向与尺度的细微波纹与涌浪，波纹随距离与风势变化，不是均匀色带或程序化条纹；
· 反射：按菲涅尔规律呈现环境反射——远处水面更接近镜面（反射天空与对岸轮廓），近处与逆光处偏漫反射；
· 倒影：倒影与实物的位置、透视、破碎程度一致，被波纹打碎但有结构，不是模糊色块，也不是"镜像贴图"；
· 通透与深度：浅水区可见水底材质与折射位移，深水区颜色随深度加深；水体有体积感而非一层平板；
· 细节：岸边湿痕与水线、浪花与泡沫、风纹、水面漂浮物；与水接触的物体有正确的接触阴影与湿润高光。
· 不出现：塑料膜感、均匀渐变带、倒影与实物错位、水面纹样重复。
```

**M6-植被**

```
植被呈现可信的植物结构与层次：
· 树冠：由成组叶簇构成的体积，受光面 / 背光面 / 透光层分明，不是扁平的绿色涂抹块；
· 枝干结构：主干—主枝—侧枝—细枝的走向清晰，叶簇朝向自然、疏密有致，外轮廓有缺口与起伏（不是实心球）；
· 叶片：同种植物的叶形与尺度统一，叶片有正反面受光差异；
· 地被：草地、灌木、花丛分层，有高差、穿插与自然边界，不是一张贴图平面；
· 树干与树皮：树皮质感与裂纹、苔痕、根部与地面的接触自然；
· 不出现：塑料绿、整体同一饱和度的色块、同株叶片形态混杂、枝叶与建筑或地面穿模。
```

**M6-树叶**

```
树叶按真实叶片重建：
· 叶簇成组生长，叶片个体轮廓清晰可辨（叶尖、叶缘、叶柄），不是绿色涂抹团；
· 半透（透光）质感：逆光下叶片呈现透光明亮与叶脉暗纹，顺光下呈现表面蜡质或绒毛的光泽；
· 叶脉结构可见（主脉—侧脉），叶片正反面颜色与光泽不同；
· 叶缘干净锐利但不出现锯齿噪声，不把多片叶合并成一整块色斑；
· 保持原图的叶量、分布、遮挡与季节色，不新增、不删除、不改变树种特征。
```

**M6-云朵**

```
云朵按真实云体结构重建：
· 云体由明确的体积与层次构成（受光面、背光面、内部阴影），不是扁平涂抹、棉絮噪声或塑料团块；
· 云型与高度层次可信（积云的团块、层云的铺展、卷云的丝缕），云底与云顶的亮度关系正确；
· 边缘：受光边缘可带半透边缘光（银边），边缘软硬有变化，不出现硬边贴图或糊成一团；
· 受光方向与太阳 / 主光一致，云缝透出天空色；云层之间有明显的透视递远关系；
· 大气透视：远处云层与天空的对比度降低、略偏冷或偏灰；
· 不出现：均匀絮状噪声、重复的云贴图、平面无体积的云、云与太阳方向矛盾。
```

**M6-地形与大气**

```
· 地形与岩石：山体、岩壁、土壤、沙地有真实的分层、断裂、风化与颗粒尺度，不是平滑曲面或噪点；
· 大气：雾霭、水汽、体积光有正确的浓度梯度与透视衰减（近浓远淡），不是一层均匀白纱或整体降饱和。
```

### M7 · 小元素与人物保真

> 分工：**剪影级远景人物与无人物的场景小元素用 M7**（只锁数量/位置）；**脸部可辨或占比明显的人物用 M8**（要修人体结构）；二者可叠加。

```
地平线上的人物、长椅、船只、车辆、旗杆等小元素保持原有位置、数量与剪影关系，不得新增或删除。
```

### M8 · 人物 / 角色与身体部位修复（看图发现人物后必挂）

> 挂 M8 时，主模板第 4 段的点名清单里**必须加入人物相关项**（面部五官、手指、发丝、皮肤、服装褶皱）——只写"重建细节"模型会忽略。

```
图1 中存在 {{数量与景别，例：中景 1 名女性角色全身；画面左下角 2 名远景行人}}。
在保持其身份、性别、年龄、体型、面部特征、发型、服装款式与配色、姿态与朝向完全不变的前提下，修复绘画化造成的全部人体缺陷：

· 解剖与比例：头身比正确，肩宽、骨盆与四肢长度合理，关节（肩、肘、腕、髋、膝、踝）连接自然；
  手指为五根、指节分明，不并指、不粘连、不多指、不少指；手掌、手腕、指甲结构完整；
  手臂与躯干分离清晰，不多肢、不融合。
· 面部：五官位置对称，双眼大小一致、视线方向一致、瞳孔与高光位置正确；鼻梁、鼻翼、嘴唇、下颌轮廓清晰可信；
  耳廓结构完整、位置正确、不缺失不重复；表情与 {{表情，例：平静微笑}} 保持一致。
· 皮肤：真实的皮肤质感与次表面散射通透感，毛孔与细纹可见，不油腻、不打蜡、不塑料、不磨皮到五官模糊；
  皮肤与衣物、头发交界处的阴影自然。
```

## 四、十四个坑（都踩过）

1. **黄昏变全局黄染** —— 模型倾向整体加暖色滤镜；**原图不是黄昏却被挂了 `M1` 时更严重（时段被整体改写）**。对策：`M1` 只在原图本就是黄昏或用户明确要求推浓时才挂 + `M2` 天空保真 + `M3` 固有色纪律。
2. **逆光剪影压黑主体** —— 单靠文字常压不动。对策：M4 + 换成同场景**日景**成品当参考图。
3. **参考图内容污染** —— 会把参考图里的城市/江景/楼体搬进来。对策：必写禁止清单，逐项列出。
4. **比例不匹配** —— 非标准比例被就近取整导致裁切/拉伸。对策：就近取值并在交付里说明。
5. **一次改太多诉求** —— "去绘画感 + 提亮 + 换时段 + 天空条款"混在一起会互相打架。一次只改一类，多轮迭代。
6. **只写"重建细节"** —— 模型会忽略。必须逐项点名（树冠/云/水/幕墙/石材接缝）。
7. **参考图挂太多** —— 单张更慢、更易顶时间预算、更易污染；**≤2 张**为佳。
8. **不看图直接洗** —— 原图里含糊的手指与脸被写实化放大成明确的多指、崩坏五官，越"清晰"越难看。对策：前置看图门 + `M8`，提交前必须完成看图登记。
9. **把卡通角色洗成另一个人** —— 强制写实化会改脸型、眼型、发色，角色身份丢失。对策：`M8-风格化条款`——保风格化比例与配色，只修结构错误。
10. **模型凭空补全画外肢体 / 背景添人** —— 没锁死时，模型会给被裁掉的手臂"接上"，或在天际线添人。对策：`M8` 负面明确"不补全画外肢体、不新增人物、保持遮挡关系"。
11. **风格参考图污染内容** —— 模型会把风格图里的建筑、江景、人物"顺带"画进来，甚至照搬构图。对策：`M9` 防护句逐项列禁止清单，并明确"图2 只告诉怎么调、不告诉画什么"。
12. **风格统一用力过猛** —— 整组图变成同一种滤镜色偏、固有色丢失（白墙染黄、绿植染棕）；人物画面还会画风漂移（被真人化或换脸）。对策：默认「中」档、`M3` 优先保固有色、人物画面不超「中」、风格化角色的画风由原图决定。
13. **自然产物被糊成色块 / 贴图** —— 树冠变绿色涂抹、树叶变色斑、水面变均匀色带、云变棉絮噪声、草地变平面贴图。对策：按类挂 `M6-水` / `M6-植被` / `M6-树叶` / `M6-云朵`，逐项点名到波纹、叶簇、叶片半透、云体受光背光，并写明"不要色块 / 不要重复贴图"。
14. **玻璃被洗成不透明板或塑料片** —— 或反射内容凭空编造（把不存在的建筑反出来）、玻璃没有厚度断面。对策：挂 `M10`，写明反射/折射规律、厚度断面、反射内容必须来自场景，并保留原图的水渍雨痕状态。
