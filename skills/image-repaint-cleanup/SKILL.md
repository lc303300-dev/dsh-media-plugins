# 洗图 · 去绘画感 / UE5 写实重渲染

把已有图片的**质感**换成写实 CG，**不改变**构图、机位、主体与设计意图。

- **用**：插画/概念图/效果图/AI 绘画 → UE5 写实质感；去笔触、涂抹感、碎裂纹理；顺带提升清晰度（输出 2K，通常大于原图）。
- **不用**：需要重新设计构图、改变内容或数量、换时段换场景 → 走 `default-image-generation` 或 `batch-image-generation`。

前置看图门、详细模板、可插拔模块（含 `M8` 人物修复）、实测坑位见 `references/repaint-template.md`（按需加载）。

## 固定参数（不要每次重新猜）

| 项 | 值 |
|---|---|
| 线路 | `comfly-gemini-flash-preview`（2K-only）——**强制点名这条线路**：单线路执行、失败即停、不回退不重放，也不自动换回平台默认的 `comfly-gpt-image-2-4k` |
| 硬门（工具层） | 洗图的每次提交都必须带 **`repaint: true`**：`generate_image` 里是参数 `repaint: true`；`batch_image` 里是 manifest 顶层的 `"repaint": true`。工具会据此把线路钉死在 `comfly-gemini-flash-preview`——**未点名会被补成 Gemini，点名任何其他线路直接 `input_error` 拒绝**（不给默认线路留口子）。只写提示词、不传 `repaint` 的提交**不算洗图**，会被当成普通出图走默认线路 |
| 线路不可用时 | 不自作主张换线路：**失败即停**并如实报告（该批可能一张都不出），由用户决定是否换线路或换新组 id 重跑。`repaint: true` 下**没有**"降级到默认线路"这个选项 |
| 分辨率 | `image_resolution: 2K` |
| 实测输出 | 16:9 → 2752×1536；21:9 → 3168×1344 |
| 候选数 | **每组 1 张**（洗图是确定性任务，不需要多候选） |
| 批量 | 多张走 `batch_image`，**并发 10**（默认，= 共享图片池上限） |
| 截止/宽限 | `deadline_seconds = ceil(张数÷10)×90 + 10`；慢速期直接给 600–1800；`completion_grace_seconds = 120` |
| 命名 | 成品 `<原名>-UE5.jpg`；对比图 `对比-<原名>.jpg` |
| 风格统一（可选） | 用户提供**风格参考图**时：图 2 = 风格参考，必挂 `M9`；批量时**同一张风格参考图挂到所有组**，保证跨图风格/色调一致 |
| 纪律 | 原图**只读**、绝不覆盖；**洗图前必须逐张看图（看图门不可跳过）**；到点硬停、不自动补跑；生成后**不做审美质检**，交用户看对比图 |

## 前置看图门（洗图前必做，不可跳过）

**提交任何一张图之前，必须亲自看图。** 洗图是把绘画感"修清晰"，原图里的绘画化人体错误（多指并指、肢体融合、面部崩坏、塑料皮肤）会被写实化**放大成更显眼的畸变**——不看图就套主模板是本技能最容易出的事故。

1. `image_preview`（最长边 1920、JPEG q85，非破坏）生成预览 → `read_image` 读预览图。`describe_image` 当前为 disabled，**不要依赖它**，看图靠自己的视觉。
2. 每张都看，不许抽样。看图必须回答并落表（模板见 `references/repaint-template.md`）：**画面里有没有人物/角色/身体部位（几处、什么景别、什么风格）**、**有没有水 / 植被 / 树叶 / 云 / 玻璃等自然产物与透明材质**、材质清单、第 4 段的逐项点名目标、要挂哪些模块。**同时登记原图的时间与天空状态（黄昏 / 白天 / 夜景 / 阴雨雪 / 棚拍，天色与云量如何）**——这决定 `M1` 能不能挂、`M2` 该怎么写。
3. **发现人物 / 角色 / 身体部位（脸、手、臂、腿、脚、背影、群像、雕像、拟人动物、玩偶机甲）→ 必挂 `M8`**（人物/角色与身体部位修复），并按景别与风格选变体：
   - 脸部可辨、或人物占画面高度 ≥10% → `M8` 完整版；
   - 只有局部部位特写（手 / 脸 / 腿 / 脚）→ `M8` 完整版 + `M8-局部特写`；
   - 远景剪影级小人（占画面高度 <5%）→ `M7` + `M8-远景精简句`；
   - 卡通 / 二次元 / 风格化角色 → `M8` + `M8-风格化条款`（保留风格化的面部比例与设计，**不得**改成写实真人）。
4. **自然产物与透明材质逐项登记，发现即挂**——这些正是最容易被糊成"涂抹色块 / 平面贴图"的地方，挂了才会被逐项点名：
   - 水（江 / 河 / 湖 / 海、水面、波纹、倒影、水花、雨雪水汽）→ `M6-水`；
   - 植被（树冠、灌木、草地、花丛、藤蔓、树皮）→ `M6-植被`；
   - 树叶（前景叶簇、树叶特写、逆光透光叶片）→ `M6-树叶`（可与 `M6-植被` 同挂）；
   - 云 / 天空主导 → `M6-云朵`（天空一律同时挂 `M2`）；地形、岩壁、沙土、雾霭与大气 → `M6-地形与大气`；
   - 玻璃 / 幕墙 / 窗 / 瓶罐 / 镜面 / 亚克力 / 车灯罩 → `M10`（玻璃与透明材质质感修复）。
5. 局部看不清时（手、脸、树叶、玻璃反射在画面里占比很小）：用 PIL 按 ROI 裁切并按最长边 1920、JPEG q85 另存，再 `read_image` 复核——**另存新文件，原图不动**。
6. 看图结论（共有几处人物、几处自然产物与透明材质、各自挂了什么模块）写进提交说明，作为交付的一部分；批量时逐张登记，不许"看一眼第一批就套用全部"。
7. **顺手确认风格需求**：用户是否给了**风格参考图**（想统一整体风格与色调）？给了就登记为图 2、按需要选强度档，并挂 `M9`；看图时也顺便判断各图的原有色温/影调差多少（差得越大越要挂 M9）。没给就不要替用户臆造风格。

## 比例（唯一允许"跟随原图"的路径）

`generate_image` 的 `image_ratio` 必填且**不得从参考图推断**。洗图场景按下面三步处理，不要静默：

1. 只读量测原图尺寸（PIL `Image.open(...).size`）。
2. 就近取 8 个标准比例之一（见下表）。
3. 在提交说明里写明"原图 W×H（x.xx:1）→ 取用 R:S"，并说明会有轻微裁切/拉伸。

| 原图比例 | 取用 |
|---|---|
| 1.75 – 1.81 | 16:9 |
| 2.15 – 2.35 | 21:9 |
| 1.45 – 1.55 | 3:2 |
| 1.30 – 1.38 | 4:3 |
| 约 1.00 | 1:1 |
| 约 0.74 | 3:4 |
| 约 0.66 | 2:3 |
| 0.56 – 0.60 | 9:16 |

## 主模板（五段，逐段填占位符）

```
【1 基准声明】
以输入图片为严格的构图与设计参考，将整个画面重新渲染为 Unreal Engine 5 风格的高品质写实 CG。

【2 必须保持】
保持原图的机位、透视、构图、主体身份、姿态、轮廓、物体比例、位置、配色及主要光源方向；
保持原图的 {{时段与光色}} 不变。

【3 重建（写实化）】
重新构建清晰可信的三维体积、表面材质和光照：使用物理合理的 PBR 材质，准确区分
{{材质清单：金属、玻璃、石材、混凝土、木材、织物、水与植被}} 的粗糙度、反射和透光特性。
呈现自然的间接光、接触阴影、合理的反射和连续的明暗过渡。

【4 去绘画感】
去除原图的绘画笔触、涂抹感、碎裂纹理和无意义的高频细节；将这些区域重建为符合物体结构的几何细节与材质纹理
（{{逐项点名：树冠枝叶体积与透光；叶片半透与叶脉；云层云体结构与边缘光；水面波纹与倒影；
玻璃幕墙分格、反射与折射；石材纹理与接缝}}）。

【5 负面与出口】
整体呈现干净、精细的电影级写实 CG，避免塑料感、玩具质感、过度锐化和随机新增细节；
不要改变 {{不可变结构清单：建筑造型、层数、开窗方式、树的数量与排列}}，不要新增或删除元素。
```

**关键**：第 4 段必须**逐项点名**最容易被糊掉的对象（树冠与树叶 / 云朵 / 水面 / 玻璃反射与折射 / 幕墙 / 石材）。只写"重建细节"模型会忽略——这是 `M6-*` 与 `M10` 生效的前提。

## 可插拔模块（按需附加，别全堆）

`M1` **黄金时刻氛围（默认不挂：仅原图本身就是该时段，或用户明确要求推浓氛围）** · `M2` **天空保真（防擅自换天 / 换时段，昼夜通用，天空一律挂）**· `M3` **固有色纪律（防全局黄染）** · `M4` **主体过暗提亮（防逆光剪影）** · `M5` 建筑/材料专项 · `M6` **自然产物专项（水 / 植被 / 树叶 / 云朵 / 地形与大气，逐项拆开挂）** · `M7` 小元素与人物保真 · `M8` **人物/角色与身体部位修复（看图发现人物后必挂，不是可选美化）** · `M9` **风格统一（提供风格参考图时必挂）** · `M10` **玻璃与透明材质质感修复（看图发现玻璃/幕墙/镜面等就必挂）**

完整文本见 `references/repaint-template.md`。常用的：

- **天空一律挂 `M2`（保真口径）**：严格沿用原图的天色、云量与云型——原图是阴天 / 多云 / 雾霾 / 暮色就保持，不得擅自换成艳蓝晴空；原图是蓝天也不得擅自改成偏白少云；无云不得凭空添云、添霞光、添日轮。天空只做质感强化（去噪、去涂抹、真实大气散射），不改时段与色相。
- **只有原图本身就是黄昏 / 黄金时刻，或用户明确要求"氛围再浓一点"才挂 `M1`**：挂 M1 只加强原图已有的光色，**不新增日轮、不改变日轮位置与太阳高度**——原图不是黄昏时挂 M1 等于擅自换时段，违反主模板第 2 段"保持原图时段与光色不变"。
- **判断"是不是过度黄昏/整体发黄"就挂 M3**：严格保留固有色，严禁全局黄色雾霭与黄/橙滤镜，暖色光只体现在天空与受光高光。
- **主体被压成黑剪影就挂 M4**：提亮到受光面与结构细节临界可读，并明确"禁止逆光剪影、主体提亮是本次最重要的修改点"。**占位符只填本图实际主体**（人物图不要写幕墙 / 层数，产品图不要写立面 / 开窗）。
- **看图发现人物/角色/身体部位就必挂 M8**：修复绘画化的人体结构错误（手指数量与粘连、肢体融合、五官崩坏、皮肤塑料感/蜡像感），同时锁死人物身份、数量、位置与朝向；**被画面裁切的肢体保持裁切，禁止补全或新增**；卡通角色保风格化面部设计、不做写实真人化。
- **看图发现水/树/树叶/云/地形就挂对应的 `M6-*`**：水面按菲涅尔规律做波纹与倒影、水体有通透与深度；树冠是叶簇构成的体积而非绿色涂抹块；叶片有半透（透光）与叶脉；云是受光/背光分明的体积而非棉絮噪声；地形岩石有分层与风化。**逐项点名才有效**，只写"自然一点"模型会忽略。
- **看图发现玻璃/幕墙/窗/瓶罐/镜面就挂 M10**：按角度呈现反射与折射、玻璃有厚度断面（边缘偏绿/青）、幕墙分格带来成组反射条带、反射内容必须来自场景；**不得把玻璃画成不透明板或塑料片**，水面用 `M6-水`、玻璃与镜面用 `M10`，可同挂。
- **用户给了风格参考图就挂 M9**：图 2 只提供"怎么调"（影调、色温、色彩关系、光比、后期质感），不提供"画什么"——内容、构图、机位、主体、物体种类与数量全部由图 1 决定；风格统一不得退化成单一色偏，固有色仍按 M3 保留。

## 参考图规范（两类参考图：风格参考 / 属性参考）

- **图 1 = 待处理画面**：唯一的内容与构图基准。
- **图 2 = 风格参考图（可选）**：用户给的"统一整体风格与色调"用图 —— 只提供影调、色温、色彩关系、光比与后期质感，**不提供任何内容**；挂它必配 `M9`。
- **图 3 = 属性参考图（可选）**：只参考某一项属性（亮度 / 材质 / 固有色 / 光色），用于救"主体过暗""材质发飘"这类单点问题。
- 顺序有语义，必须与提示词里的"图1/图2/图3"对齐；**参考图总数 ≤2 张**（不含图 1）——"风格参考"与"属性参考"要挑最需要的那张，不叠挂。
- 挂任何参考图都**必写防护句**（风格参考版更严）：
  「图2 仅用于参考【风格与色调：影调 / 色温 / 色彩关系 / 光比 / 后期质感】；绝不引入图2 中的任何物体、建筑、人物、城市天际线、江面、船只、塔、道路、地形或标志性元素，不照搬图2 的构图、机位、景别与主体。」
- 选图经验：想让过暗主体变亮，选**同场景「日景」成品**比「黄昏」成品有效得多（实测主体 L\*：无参考 41.5 → 黄昏版参考 45.4 → 日景版参考 54.7）；只想把氛围推浓才用氛围图；想最干净就不挂参考图（主体黄染更低，氛围强度略降）；**要统一一组图的风格，只挑一张风格参考图并让所有组共用同一张 + 同一段风格描述**。
- 风格统一与固有色纪律的边界：`M9` 作用于影调层、`M3` 保固有色——"色调统一"不等于"全局色偏"；人物画面的风格强度建议不超过"中"档（M9 强度三档见 `references/repaint-template.md`）。

## 客观自检（量化迭代，不做审美判断）

| 指标 | 算法 | 判读（**与原图同区相减，只看变化量，不看绝对值**） |
|---|---|---|
| 色彩偏移 | 全图 / 天空区(上1/3) / 主体区(下2/3) 的 `R − B` 均值，**减原图同区均值** | Δ ≈ 0 ~ +15 属正常质感增强；Δ ≥ +30 或全图普遍偏黄 → 跑偏，挂/加强 `M3` |
| 主体亮度 | 主体 ROI 的 LAB `L*` 均值，**减原图** | Δ ≥ 0（没被压暗）为目标；Δ ≤ −8 说明主体被压黑 → 挂/加强 `M4` |
| 天空暖度 | 上 1/3 的 `R − B`，**减原图** | 原图本身是黄昏时 Δ 可为正（推浓氛围）；**原图本来不是黄昏时 Δ 应 ≈ 0，出现明显正偏差说明擅自换了时段，撤掉 `M1`** |
| 保真复核 | 与原图同位置目检构图 / 数量 / 遮挡 / 天空云型 / 有无日轮 | 位置、数量、云的形状、日轮的有无与位置均不得变化 |

> **不要用绝对档位判断**：原图可能是夜景、阴天、正午或棚拍，绝对的 `R − B` 与 `L*` 没有统一合格线，只有"相对原图的变化量"才是判据。仅当原图本身就是黄昏时，才可参考"天空区 R−B 50–85 中等、100+ 强"这类经验区间。

**人物结构复核（看图发现人物时，属于结构检查、不是审美判断）**：把人物 ROI 裁切放大后目检——手指数量与粘连、双眼对称与视线、肢体连接处、耳廓与发际线、服装是否穿透身体、被画面裁切的肢体有没有被凭空补全。发现结构性缺陷（多指/断肢/多肢/面部崩坏）只**报告用户并给出重跑建议**，不自动重跑、不打审美分。

自检只用于判断"是否跑偏"，**不代表替用户做质量验收**；人物结构复核同理，最终验收交用户看对比图。

## 执行与交付

0. **看图**（前置看图门）：`image_preview` → `read_image` 逐张确认，登记人物/角色/身体部位并按景别挂 `M8` 变体，同时确认有没有风格参考图 —— **这一步没做完不许提交**。
   **提交前再确认一次线路**：`repaint: true` 已带上（单张传参数、批量写 manifest 顶层），否则工具不知道这是洗图任务，会走默认线路。这是洗图唯一允许的线路口径，不接受"先用默认线路试试"。
1. **单张** → `generate_image`（**必带 `repaint: true`**；`image_provider` 可省略，工具会补成 `comfly-gemini-flash-preview`，也可显式写上以留痕；`image` = `[原图]`，或 `[原图, 风格参考图]` 做风格统一，或 `[原图, 属性参考图]` 救亮度/材质；风格与属性参考图**不叠挂**）。
2. **多张** → 构造 manifest（每组 1 候选、**顶层 `"repaint": true` 与 `"image_provider": "comfly-gemini-flash-preview"` 都写上**、`reference_images` 按语义顺序）→ `batch_image(command="start", manifest_path=…)` → `status` 轮询 → 结算后自动出审阅页；再补逐张左右对比图。**要做风格统一时，每组的 `reference_images` 都写同一张风格参考图、风格段逐字一致**——这是跨图一致的关键。缺 `repaint` 的 manifest 会被工具当作普通批次，**很可能落到默认线路上去**。
3. 交付：成品（原尺寸，不缩小）+ 对比图 + 交付路径 + 原图比例与取用比例差异说明 + **看图结论（原图时段与天空状态 + 人物/身体部位 + 自然产物 + 透明材质清单与各自挂载的模块）** + **风格统一说明（是否挂了风格参考图、用了哪一档强度、是否所有图共用同一张）**；**原图未覆盖**。
4. 需要重跑某张：冷却 2–5 分钟后换新组 id（同一 manifest 会被 job key 去重拒绝）；重跑时**仍要带 `repaint: true`**（重跑同样不许落到默认线路）；因人物畸变重跑时，在提示词里加强 M8 对应条款（手部/面部）后再提交；因风格不统一重跑时，检查是否所有组共用同一张风格参考图与同一段风格描述。
