## 使用边界

本文件保存社区创作者积累的完整方法谱系。它们可提高表达精度，但不是官方规范，也不能保证跨平台复现。先确认镜头确实需要，再选用；若与当前平台文档冲突，以平台适配器为准。

## FOV 锚点表

**社区经验**：使用少量离散 FOV（field of view，视场角）作为稳定的构图锚点，避免连续堆叠随机数值。毫米等效只用于帮助理解视觉效果，不代表真实镜头校准。

| FOV | 近似视觉参照 | 常见用途 |
|---:|---|---|
| 180° | fisheye（鱼眼） | 主观眩晕、梦境、球形畸变 |
| 107° | 14–16mm 超广角感 | 巨大室内、强透视建立镜头 |
| 84° | 20–24mm 广角感 | 群体调度、动作、环境建立 |
| 63° | 28–35mm 观察感 | 纪实、沉浸式近距离环境 |
| 47° | 40–50mm 中性感 | 自然视角、中景、通用建立 |
| 29° | 75–85mm 肖像压缩感 | 对话、半身隔离、浅景深 |
| 18° | 100–135mm 长焦感 | 身份稳定的面部近景 |
| 12° | 180–200mm 远摄感 | 远处细节、空间压缩 |
| 8° | 300–400mm 超远摄感 | 体育转播、远距离观察 |

**实验性启发**：多镜头中可为每段固定一个锚点，并写“本段视场角保持稳定（no drift mid-segment）”。精确角度可能被模型近似，不应作为测量保证。

## 特殊光学模式

以下组合是社区启发式配方：

- **Observation pattern（隐蔽观察感）**：远距离 8°–12° 远摄 + 占画面约 20%–30% 的失焦前景遮挡 + 主体之间的雾尘/热浪。不同段落可换遮挡物，但保持观察位置连贯。
- **Sports broadcast（体育转播感）**：约 8° 超远摄 + 轻微手持震动 + 摄影机在远处努力追踪动作。
- **Detail-on-wide / snake cam（广角贴物细节）**：约 84° 广角贴近小物体的低机位，使前景夸张、背景纵深展开。
- **Intimate wide（亲密广角）**：63°–84° 广角贴近面部，主体居中，同时保留可读环境。
- **Tele compressed air column（长焦空气压缩）**：8°–12° 下强调主体与相机间被压缩的尘埃、雾或热浪层。

## 极端 FOV 多镜头协议

**实验性启发**：社区在 8° 或 107° 等极端视角的多镜头中采用四层一致性协议，以减少数镜后视角漂移：

1. 建立整段统一的身份、地点与空间锁定。
2. 每段开头给出 lens lock（镜头锁），明确该段 FOV 和构图作用。
3. 每段结尾用 lens check（镜头复核）简短重申该段视角保持不变。
4. 色彩用材质、受光方式和画面职责来描述，不用孤立色名清单。

四项可作为完整测试方案，但“缺一必败”并非可证实的官方规律。镜头简单时应减轻协议，避免提示词过载。

## Whip pan 节奏

**社区经验**：whip pan（甩镜/急摇）需要留出起点稳定、模糊运动和终点重新落稳三个阶段。可用以下节拍作为初始试验：

- 约 0.3 秒：主体 A 构图可读。
- 随后约 0.8 秒：快速横摇形成方向性 motion blur（运动模糊）。
- 到约 1.4 秒：主体 B 重新清晰落稳。

过短的甩镜可能更像硬切，这是经验观察而非固定阈值。描述其动机更重要，例如跟随说话者、追随抛出物或用模糊遮蔽空间转场。

## Mixed speed 混合速度

**社区经验**：real-time（实时）与 slow motion（慢动作）混用时，让单个镜头内部保持一种时间速度，并用明确切点在速度模式间转换，通常比镜头内频繁变速更稳定。

- 需要镜头内变速时使用 speed ramp（速度渐变），注明触发动作、进入点、最低速度阶段和恢复点。
- 需要精确动作可读性时，优先 `HARD CUT（硬切）` 分隔实时与慢动作。
- 变速比例（例如 40%）只作为实验锚点；应同时写出可见效果，如水滴悬浮、衣摆运动变慢、撞击瞬间延长。

## Anti-impact 无撞击破裂

**实验性启发**：当玻璃、墙体或物体应因持续压力而开裂，而不是被击打破裂时，使用 anti-impact lock（无撞击锁定）：

- 把施力写成持续挤压、弯曲或边缘应力，而不是挥击。
- 明确裂纹由边缘或结构薄弱处产生，逐步向内部推进。
- 描述不存在单一撞击中心，裂纹形态服从压力路径而非放射状冲击。
- 将时间顺序写成“受压变形 → 边缘出现细裂 → 裂缝延伸 → 局部脱落”。

在生成提示词中优先用正向目标表达，例如“人群持续推挤玻璃表面”“裂纹从受压边框向中心蔓延”；必要时可补一句排除冲击点，但不必机械追求全篇只有正向句。

## 数值化与正向表达

以下均为社区经验，不能升级为硬规则：

- **运动速度**：km/h 可帮助表达车辆或明确路径运动，但摄影机 pan（摇摄）的视觉速度通常更适合用完成时长、角度和画面结果描述。
- **大气介质**：雾密度百分比、可见深度米数可作锚点；优先写主体轮廓、背景衰减和光束可见程度。
- **渐进气氛**：多镜头中逐步加深雾、尘或烟能强化戏剧升级，但须有场景内原因。
- **巨大尺度**：与人、门窗、车辆等熟悉物体比较，比单独写“巨大”更直观；真实尺寸仍可保留。
- **Positive phrasing（正向措辞）**：描述期望状态通常更有效；但安全边界、合规限制或关键排除项可以清晰直说。
- **设备名称**：描述影像特性通常比堆叠摄影机、胶片或导演名字更可迁移；用户明确要求特定视觉参考时，转译为可见特征。
