# AI 视频拍摄硬规则（2026-11-07 用户定，优先级最高）

> 本文件是**强制规则**，优先级高于本技能其他所有写法建议；与 `jimeng-standard-template.md`、`prompt-structure.md` 冲突时，以本文件为准。
> 适用：所有 AI 视频提示词生产（导演线单条/批次、短剧线、Skill 线）。

## 一、参考图只是参考，绝不能 1:1 出现在成片里

场景卡、参考图、实景照片只提供四件事：**空间关系、材质、建筑体量、光色基调**。

**禁止**：成片出现与参考图构图一致的画面——同机位、同景别、同透视、同主体位置。直接拿场景卡当背景板 1:1 生成，是这类片子最典型的废片来源。

**必须**：每个镜头都"在参考场景里重新架机位"，正面写清：

- 机位高度（1.2m / 1.5m / 1.9m / 航拍 120m）
- 机位角度（平视 / 仰 5° / 俯 25° / 俯角 60°）
- 焦段（24mm 广角 / 35mm 标准 / 50mm 中焦 / 85mm 长焦）
- 主体在画面的前中后景位置

参考图里的人物、人群、车辆、文字排版、卡片分格、白底与投影，一律不得作为画面元素迁移。

- ✅ 正面写法：「机位在街对面 1.6 米高、35mm、微仰 5°，画面右侧进深是弧形店招，人物在中景偏左」
- ❌ 禁止写法：「参考图片1的画面」「与场景卡一致的构图」「背景使用场景卡」

## 二、有人物的场景，禁止多场景无缝转场

画面里一旦出现角色，**场景切换只能用硬切**，且必须用人物特写做跳板：

- 脚步特写（布鞋踩石板、迈过门槛）
- 面部特写（愣半拍、笑出来、抬眼）
- 手部特写（接票、抽票、递东西）
- 衣摆/道具特写（大褂下摆扫过、票面翻起）

**禁止**"镜头跟着人从一个场景滑到另一个场景"。这种写法在有角色的段落里一定会崩：人会漂、景会糊、空间会乱。

- ✅ 「脚步特写落在府门石板 → 硬切 → 门内两人中景」
- ❌ 「镜头跟随两人从商圈一路滑到校门口」

一个节点内如果需要换场，**最多换一次**，且必须用特写做桥。

## 三、不要一镜到底，用符合镜头语言的景别切换

默认**不用长镜头**，除非用户明确要求。角色做任何动作，都先给该动作的**局部特写**，再切中景/全景交代环境：

| 动作 | 标准镜头序列 |
|---|---|
| 接票 | 手部特写接住飘落的票 → 硬切 → 两人中景 |
| 取票 | 手探入大褂内襟的特写 → 硬切 → 胸前持票中近景 |
| 递票 | 票面朝镜头推近的特写 → 硬切 → 对方中景 |
| 喝茶 | 茶盖刮沫的特写 → 硬切 → 双人中景 |
| 起身 | 手撑膝盖、鞋跟离地的特写 → 硬切 → 站起来的中全景 |
| 扬票 | 票面擦过镜头的特写 → 硬切 → 新场景全景 |
| 入门 | 脚步跨门槛的特写 → 硬切 → 门内全景 |
| 说话 | 人物近景（口型清楚） → 切对方反应近景 → 切双人中景 |

**每个节点至少 3 个景别**，形成"特写 → 中景 → 全景"的节奏。景别变化要服务于信息：特写给细节与情绪，中景给关系，全景给环境。

## 四、长镜头的两种合法形式（2026-11-08 修正）

默认不用长镜头（见第三节）；用户明确要求时，只走下面两种形式之一。

### 4.1 物理遮挡穿越

1. **主体始终占画面 50% 以上**，是紧贴的特写跟随镜头
2. **换景靠物理逻辑**：穿过楼间缝隙、被建筑遮挡后露出新场景、穿过树冠、从桥下穿过、钻进隧道

每个穿越点写明「被什么遮挡、从哪露出、露出后是什么」。

- ✅ 「票掠过一栋楼的山墙，被墙面完全挡住的半秒里场景已换成十字路口」
- ❌ 「镜头跟随票从空中飞到城市，一路经过各种建筑」（无物理逻辑，必糊）

### 4.2a 连续飞行／穿梭·有主体（2026-11-08 实测成功，不靠遮挡）

这次"票带镜头飞漳州"验证了：**不用任何遮挡，也能做出干净的一镜到底**。关键不在遮挡，而在"**主体固定在镜头前 + 风景按顺序连续滑过**"。

六条写法：

1. **主体是镜头附件**：票贴在镜头前、占画面一半以上、位置不动（详见第十四节）。它是"画面的前景框"，不是画面里飞行的物体。
2. **风景按顺序列**：每一镜只写"这一镜下方/上方**滑过什么**"，按真实飞行顺序依次排（路口 → 大道 → 河湾 → 公园 → 跑道 → 落点）。顺序本身就是空间线索。
3. **连续动词**：用飞越 / 掠过 / 擦过 / 贴着 / 滑过；**不用**"切到""换到""来到另一个地方"。
4. **方向单一**：只向前、缓慢下降；不回头、不后拉、不横向漂移。
5. **不切不遮**：全程一个镜头，不靠遮挡换景——观众是靠"飞过的地标顺序"感知空间在移动。
6. **首尾收口**：开头主体贴满画面进场；结尾主体退到画面中央落点。

- ✅「票仍贴在镜头前，位置不动；笔直的大道在票的上方展开、向后流走」→ 下一镜「河湾的水面与倒影在票的上方掠过」
- ❌「镜头跟随票飞过城市，途中经过各种建筑与街道」

### 4.2b 无主体穿梭（2026-11-08 用户预告，后续会做）

没有前景道具时，连续性**全靠空间本身**——这是最容易"空间漂移"的类型（上一镜还在街面，下一镜突然飘到城市上空）。五条写法：

1. **方向锚定开头**：每镜第一句写"镜头沿着刚才那条大道的方向继续向前"，把上一镜的空间明确接过来；不要每镜重新起一个"镜头看到……"。
2. **高度与速度写死**：匀速前推、高度缓慢下降；不加速、不减速、不上升。速度一变，观众立刻感到"跳了"。
3. **地标顺序链**：把要经过的地标排成一条链（路口 → 大道 → 河湾 → 公园 → 跑道），每镜只负责其中一段，位置顺序不能乱。
4. **每镜必须有穿越感的动词**：飞越 / 掠过 / 擦过 / 穿过 / 贴着水面——不用"看到""出现""来到"这类静态词。
5. **不切镜、不变速、不回头、不后拉**：全程一个镜头，方向单一。

- ✅「镜头沿着刚才那条大道继续向前，掠过路面上的斑马线」→「速度不变，镜头压低到河面上方，水面的反光从画面下缘滑过」
- ❌「镜头看到一片河湾」→「镜头出现在城市上空」（没有任何空间承接，等于重新开场）

**判断标准**：遮不遮挡、有没有主体都不重要，**"每一镜是否有明确的空间承接与推进"**才重要。有承接＝一镜到底成立；每镜各自开场＝必糊。

## 五、即梦是正面提示词驱动的模型

主体描述必须写成"画面里出现什么、怎么动、镜头怎么走"，**不写"不要怎样"**。负面约束只保留在 `[稳定性限制]` 段，且不超过 3 条。

| 负面（禁止这样写） | 正面（改成这样写） |
|---|---|
| 不要静态摆拍 | 人物持续向前走，脚步带动大褂下摆摆动 |
| 不要拉远 | 镜头保持中景，仅横向移动 |
| 不要浮夸动作 | 手部动作幅度克制，只有手指与手腕发力 |
| 不要出现文字 | （不写，改用真实地点名交代） |

## 六、每个镜头的四件套（缺一即不合格）

1. **景别**：特写 / 近景 / 中近景 / 中景 / 中全景 / 全景 / 大全景
2. **机位**：高度 + 角度 + 焦段
3. **主体动作**：谁、做什么、怎么开始与结束
4. **主导运镜**：推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕，写清方向与速度

## 七、交付前硬检查

- [ ] 有没有任何镜头是"参考图 1:1 构图"？有就重写机位
- [ ] 有人物的段落里，换场是不是靠特写硬切？有没有"跟随人物滑过两个场景"
- [ ] 这个节点是否至少 3 个景别？有没有出现整段一镜到底
- [ ] 动作类镜头是否先给了局部特写，再切中景/全景
- [ ] 若保留长镜头：主体是否占画面 50% 以上、切换是否靠物理遮挡
- [ ] 主体描述是否全部正面表述？负面约束是否只有 `[稳定性限制]` 那几条

## 八、画面内容与镜头分开，但必须逐镜编号一一对应（2026-11-07 定稿）

> 中途试过"把镜头化进画面描述"，实测画面与镜头仍然衔接不上；**定稿为分开 + 逐镜编号**。

结构固定为两个区块，缺一不可：

```
【画面内容】
镜1：……
镜2：……

【镜头】
镜1 景别｜机位高度+角度+焦段｜运镜｜这一镜的主体动作
镜2 ……
```

铁律：

1. **镜数必须相等**：画面内容几段，镜头就几行，差一个都不合格。
2. **镜号必须一一对应**：镜1 的画面讲的是镜1 的机位看到的东西。
3. **【画面内容】只写发生什么**（谁、做什么、环境里有什么），不写景别/焦段/运镜。
4. **【镜头】只写怎么拍**（景别｜机位｜运镜｜动作要点），不重复叙事。
5. **画面内容每段前写 `镜N：`，镜头每行以 `镜N` 开头**——两道编号缺一不可。
6. 写完必须机械校验：`镜数 == 段数`，不等就返工。

## 九、浏览式镜头方法论：视线匹配 + 动作拆解（2026-11-07 用户定）

角色的"看"和"做"，都要拆成**成对的两个镜头**：先拍人物，再拍他看到/做到的东西。观众是透过角色的眼睛看世界的，不是被镜头硬塞一个全景。

### 9.1 视线匹配（eyeline match）

**结构**：角色看（反应近景）→ 切到被看的东西。

**被看的东西用什么景别，由"想让观众知道什么"决定，不强制接中景或全景**：

| 想让观众知道 | 被看对象的景别 | 例 |
|---|---|---|
| 是什么细节 | **特写** | 甲看操场 → **学生跑步的脚与扬起的尘土（特写）** |
| 谁在做什么 | **中景** | 甲看操场 → 几个孩子在追跑（中景） |
| 这是哪里、有多大 | **全景** | 甲看操场 → 环着跑道的草坪与操场全景 |
| 一个具体信息点 | **特写/中景** | 甲看校门口 → 校名墙上的字（中景） |

**所以"反应近景 → 被看对象特写"完全合法**，而且常常比"近景→全景"更高级：特写给的是细节的冲击，全景给的是空间的交代，两者不冲突，可以连着用（反应→细节特写→环境全景）。

### 9.2 动作拆解

角色做动作，同样拆两镜：
1. **动作局部特写**：手、脚、道具（接票的手、迈步的鞋、拍桌的醒木、刮沫的茶盖）
2. **接动作的结果或关系**：道具到了谁手里、人走过了门槛、两人之间的反应

### 9.3 铁律

- **成对出现**：有反应镜头就一定要有被看的对象；有被看的对象就要先给反应。只有一边就是废镜。
- **禁止监控视角**：全景里人物一路走过、背景换了一个又一个——观众既看不到他们的反应，也不知道他们看见了什么。这是监控，不是导演。
- **禁止纯空镜**：环境镜头必须挂在某个人的视线或动作后面，不能凭空插一段风景。
- **景别服务于信息**：特写=细节，中景=关系，全景=空间。选景别前先问"这一镜要让观众知道什么"。
- **不做硬性层级**：不需要"特写必须接中景再接全景"。相邻两镜可以直接从特写跳特写，只要视线/动作的因果说得通。

### 9.4 组合示例（一段浏览）

| 镜 | 景别 | 内容 |
|---|---|---|
| 1 | 中全景 | 两人走进园区，建立空间（只交代一次） |
| 2 | 近景 | 甲侧头、眼睛动，往一侧看 |
| 3 | 特写 | 他看的：孩子手里举起的玩具 |
| 4 | 近景 | 甲笑起来、弯腰 |
| 5 | 特写 | 甲的手接过玩具 |
| 6 | 全景 | 拉出：整座乐园的尺度 |

## 十、越轴纪律：被看对象镜里不能出现看的人（2026-11-07 用户定）

视线匹配的第二镜（被看对象），**画面里不要再出现刚才看它的那个人**。

- 反应镜：甲在画面里侧头看店招（85mm 近景）
- 被看对象镜：**画面里只有店招与橱窗**（85mm 特写），不出现甲

原因：如果第二镜里又把甲放进画面右侧/前景，观众的眼睛会在两镜之间被拉回人物的同一侧，镜头轴线就翻了——成片看起来是"他突然换了个方向站着"。这是典型的越轴。

**唯一例外**：需要过肩镜头（over-the-shoulder）时，必须在提示词里明确写"过肩视角：画面左下是甲的肩与后脑虚焦，右侧是他看的店招"——写了才用，不写就不要出现人物。

**同理适用于动作镜**：动作局部特写（手、脚）之后的第二镜，回到人物中景时，人物要在画面的同一侧继续（谁在左就一直在左）。

## 十一、场景切换后**默认**用特写开场（2026-11-07 定，2026-11-08 改为默认项）

视频是**分段生成**的，段与段之间空间是断的。**新场景默认用特写开场**，用细节把注意力钉住，观众就不会去追究上一段的空间去哪了。

| 节点 | 默认开场 |
|---|---|
| 片头（全片第一个节点） | 大全景或中全景建立 |
| 其余节点 | **优先特写**（局部细节、道具、手、脚、面部近景） |

**这是默认项，不是硬性规定**——以下情况可以用中景或全景开场：

- 需要立刻交代空间尺度（如"这是一整座乐园"的震撼）
- 上一段结尾已经把观众带到门口，观众正等着看"里面是什么"
- 特写开场会和上一段结尾的镜头重复（比如都是脚步特写）

结构通常是：**开场镜 → 中景/全景建立空间 → 人物与动作**；开场镜用特写还是全景，按需选。

常用开场特写：脚步踩地 / 跨门槛、手接东西、茶盖刮沫、水花炸开、檐口光影、票面翻起、脚灯亮着。

## 十二、【限定】第一条必须是"禁止加背景音乐"（2026-11-07 事故）

每次写【限定】，第一条必须是 **禁止加背景音乐**。漏掉这条，模型会自己配 BGM，后期去不干净。

标准四条（逐字可用）：

```
【限定】禁止加背景音乐；禁止加文字与字幕；不做慢动作；不许把两个镜头运镜连成一个、不瞬移。
```

之后可追加本段专属禁止项（如"不出现第二张票"），但**四条基线一个都不能少**。

交付前必须 grep 一遍：`禁止加背景音乐` 出现在每一段【限定】里，缺一段就返工。

## 十三、交付前自动自检清单（每批必跑）

写完一批提示词，用脚本跑完这几项，全绿才交付：

1. **镜数 == 画面内容段数**（逐节点）
2. **每段【画面内容】都有 `镜N：` 前缀**，每行【镜头】都以 `镜N` 开头
3. **每段【限定】都含 `禁止加背景音乐`**
4. **11 个区块齐全**（风格/布光锁定/参考/设定/特殊要求/导演/故事背景/画面内容/镜头/一致性/限定）
5. **每段长度 < 4000 字符**（2.0fastvip 限制）
6. 除片头外，**每段第一镜默认是特写**（非硬性，可按需换中景/全景）
7. **素材引用数**：图 ≤9 / 音 ≤3，逐个节点核对

## 十四、固定前景道具（道具带镜头飞）怎么写才不会中途消失（2026-11-07 事故）

**现象**：道具（票、手机、卡片）在画面下缘或前景出现，第 1–2 秒还在，飞到中段就消失了，后面全程没有它。

**原因**：写成"画面下缘伸出一张票""票出现在画面前景"——模型把它当成**入场元素**，按叙事逻辑"出现完就该走了"。

**正确写法**：把道具写成**镜头附件**，不是画面里的物体。

| 错误 | 正确 |
|---|---|
| 画面下缘伸出一张票 | 镜头前横着一张票，**像贴在镜头上一样** |
| 票固定在画面中央 | 票**贴在镜头前**，位置不动 |
| 票占画面 80% | 票**左右边缘贴着画面的左右两侧**，占住画面下半部分一大块 |

**三条硬约束，缺一就会丢**：

1. **比喻成镜头附件**：用"贴在镜头上""贴在镜头前""横在镜头前"这类说法。
2. **每镜重复锚定**：每一个镜头的【画面内容】开头都写"票仍贴在镜头前、位置不动"；每一行【镜头】都写"票占画面下半部分一大块"。不能只在第一镜提、后面省略。
3. **【一致性】写死"每一镜都必须还在"**：`票从第一帧到最后一帧都贴在镜头前，不消失、不飘走、不换位置；每一个镜头里票都必须还在，一镜都不能空。`

**另一条保险**：给道具**边缘贴画幅**的位置（左右边缘贴住画面两侧），比"占画面 80%"更容易保持——模型对"物体贴边"的稳定性远高于"物体居中占比例"。

## 十五、画布工作流：先建图片节点，再建视频节点（2026-11-07 用户纠正）

在即梦画布上做片子，**顺序不能乱**：

1. **先把所有参考图建成图片节点**（角色卡、场景卡、道具卡）：`node create image`，按角色 / 场景 / 道具分三列排在画布左侧。
2. **再建视频节点**：`node create video`，提示词里用 `{{node:图片节点id}}` 引用这些图片节点。
3. 视频节点【参考】里的素材**必须**是 `{{node:...}}` 或 `{{res:...}}`；裸标签"图片1"在画布正文里只是普通文字，**不会建立任何引用**。
4. 布局：图片节点在左（角色列 / 场景列 / 道具列），视频节点按批次在右——一批一列，`y` 从 0 开始每条 +420。

**反例**：跳过图片节点直接建视频节点，提示词里写"图片1为甲"——画布上根本没有图1，视频节点等于零参考，画面全靠模型自由发挥，角色和场景全飘。

**验收**：`node show` 读回 `generation.references`，引用数应等于素材数；`upstreamNodeIds` 里应能看到对应的图片节点 id。只有 `text` 段没有 `reference` 段 = 没绑上。

## 十六、台词：放单人镜、按语速核时长（通用原则）

- **台词放单人镜**，并写明"画面里只有他一个人、另一个人不在画面内"。只写"与甲面部齐高的近景"时，两个人可能都进画面，模型会随便挑一个开口。
- **按角色语速核时长**：台词字数 ÷ 该角色语速 = 需要的秒数，镜头时长必须够；不够会被压语速、甩给另一个人或截断。
- 台词前可加一句口语起势让语流自然，起势词可独立成句、停顿后再进正题。

（具体角色的语速、台词文本属于项目资产，见项目文档，不写进本文件。）

## 十七、镜数要与时长匹配（2026-11-08 教训）

- 平均每镜 **1.5–2.5 秒**。9 秒的段塞 9 镜 = 1 秒/镜，太碎，观众还没看清就切了
- 各类型建议时长：建立镜 2–2.5s ／ 反应镜 1.5–2s ／ 特写 1–1.5s ／ 落点 0.8–1.5s
- 顺序是**先定段时长**，再按"台词秒数 + 动作镜 + 转场镜"倒推镜数；不要先定镜数再往里塞
