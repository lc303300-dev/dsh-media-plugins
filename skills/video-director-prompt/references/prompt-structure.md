## 结构选择

官方 13 份范例归纳出 **5 个模板**，按"有没有分镜、要不要卡点、有没有参考视频"选（完整决策表见正本第〇节）：

1. **T1 `镜头N` 编号式**：有分镜、逐镜推进。允许 `镜头1-2` 合并段、冒号可省、分号或换行分隔。
2. **T2 时间轴式**：有分镜且要精确控制每段时长/节奏。`0-1.5秒:` 或 `[00.0-03.0秒|场景名]`，
   可挂 `[素材说明]`/`[整体设定]`/`[时间轴]`/`[稳定性限制]` 区块头，每段音效单独成行。
3. **T3 单一镜头 · 内部时间轴**：一个镜头内的连续变化（延时、渐变、变形、单镜头叙事）。
4. **T4 单镜头连续（一镜到底式）**：一个镜头、运动不中断、不要时间轴。
5. **T5 视频驱动**：有参考视频，迁移它的运镜/动作到新主体与新场景。

**同一层只用一种分段手段**：不要在同一批镜头上既写 `镜头N` 又写 `[00.0-03.0秒|…]`。
多个模板可叠加（如 T2 的时间轴 + T5 的视频驱动）。

只有一个镜头就只写一段，不要为了"像模板"硬凑编号。控制越多，越要检查要素之间是否互相冲突、
镜头数量与时长是否现实。

## 要素语义

[正本第二节](jimeng-standard-template.md) 给的是**整段覆盖项**：主体动作、素材绑定、景别/机位、主导运镜
（范例实测覆盖率 11/11、10/11、9/11、7/11），**个别镜可省略**、素材可沿用上一镜；
材质细节、光影环境、局部约束、`时长` 按需。

> **顺序灵活**：范例里动作常先于景别（范例 01 镜头1 先写主体动作再补景别与前景细节；范例 03 镜头3
> 先写动作、再给运镜、再给素材）。默认按上列次序写只是可读性建议。

各要素回答的问题：

- **景别 / 机位**：观众离主体多远、从哪个高度角度看。
- **主体与动作**：谁、做什么、动作如何开始与结束。**必须与相机动作分开写**。
- **素材绑定**：本镜实际出现或发挥作用的素材。没出现的素材不要引用。
- **材质与细节**：皮肤、毛发、布料、液体、金属的表面与物理状态。
- **主导运镜**：一镜一个；运镜要服务于信息、情绪或空间变化。
- **光影环境**：光源、方向、软硬、曝光关系与环境介质。范例用**三层**写法（见"风格分布"）。
- **局部约束**：只写当前需要排除或必须保持的那一项，**内联在该句里**，不做段级负面清单。
- **时长**：要卡点就用 T2 的时间轴标题；否则交给工具参数。

## 素材语义

官方范例把素材按**角色**分工，提示词里逐份声明（范例 06 的 `[素材说明]` 是标准形态）：

| 角色 | 说明 | 范例 |
|---|---|---|
| 首帧 / 构图 | 决定开场画面；`_构图` 版是去掉前景遮挡的构图版 | 单一 01 `图片56为首帧参考` |
| 场景 | 环境底图，可跨范例复用 | `图片32` 咖啡店街角 |
| 人物三视图 | 正/背/近景，锁身份、服装、身形 | `图片49作服装参考`、`图片47` |
| 正脸五官 | 纯背景正脸照，只管脸与发型 | `五官参考 Stati..2.png` |
| 道具 | 道具多视图，锁材质与细节 | `手中道具参考:图片75` |
| 配角 / 动物 | 次要主体设定 | `Stati..8`、`图片106` 小狗三视图 |
| 变形 / 替换对象 | 逐个替换的目标物 | `图片18` 仙人掌、`图片20` 鸵鸟 |
| 多角色分配 | 一张图含多个角色，逐个分配 | `其他角色分配给四个坏人1图片28` |
| 参考视频 | 只用它的运镜与动作（T5） | `飞书202...7.mp4` |

写法纪律：

- 每份素材分配**单一职责**，并说明什么**不要**从它迁移（`仅参考指定主体，不迁移原图背景和无关人物`）。
- 最终写成中文裸标签 `图片N`，直接内联在它描述的对象后面；**不在段末集中罗列**。
- **同一素材全片沿用同一编号**（范例 01 的同一只蜘蛛多镜都写作 `图片2`）。
- **禁用** `@Image1`、`@img1`、`@Image1`、`@图片1`、`参考图片1` 等形态。
- **官方原形编号 ≠ DSH 落地编号**：官方用的是素材库内文件名编号（可跳号、可带 `(2)`、跨范例复用），
  DSH 要求按 **图片 → 视频 → 音频 的传入顺序**重编号。转换规则与示例见 [正本第七节](jimeng-standard-template.md)。
- 内部可先用语义标识（`character-main`、`first-frame`、`motion-reference`），交付前统一换为裸标签；
  **不得**把内部文件名或别名留在正文里（会被判为泄漏并拒绝）。
- 参考图已确定外貌时，文字只补年龄段、体型、当前状态、动作关键特征，以及有台词时的声音。
- 每次生成视为独立文档：删除场次编号、前情摘要、未使用角色以及"延续上一镜"等外部依赖。

## 风格分布

**通用原则**：把风格写进它实际控制的要素里，不要用孤立的"风格词前缀"代替具体场景设计。

- **光影写三层**（范例 01/02/04 的标准形态）：
  `光影: <光源层>，<光行为层>，<色调层>` —— 光从哪来 / 光在画面里怎么起作用 / 整体调子。
- 表演质感写进主体动作；镜头特性写进景别·机位与运镜；物理真实感写进材质与细节。
- 段级质感句（`真实拍摄质感，真实皮肤纹理质感。`）放**末尾**、只写一次；**不要**在开头搭"风格/场景/角色"区块头。
- 画质规格写进 `[整体设定]`（T2）或开头（T1/T3/T4）的自然语句：`12秒，16:9，720p，写实电影质感`。
- 分辨率、帧率、码率、模型参数属于末端输出适配，交给结构化参数，不写进正文。

## 转场与时间

- **分段手段与模板绑定**：T1 用 `镜头N`；T2 用 `0-1.5秒:` 或 `[00.0-03.0秒|场景名]`；
  T3 用镜头内的阶段时间轴；T4/T5 按事件顺序写、不切时间轴。
- **时间码与秒数区间标题是合法写法**（官方范例 04/06 与单一 01/02 都在用），
  包括 `0-3秒:`、`[00.0-03.0秒|标题]`、`[00:00-00:05] 镜头1：`。**只有管道符拼接形态被代码层拒绝**
  （`0.0-4.0 秒｜第一段｜图片2`）。
- 镜头**内部**的切点用 `CUT_02 硬切至…` 声明（范例 03），不要另起一个 `镜头N`。
- 需要"某段不可缩短"时显式写死并逐秒拆解（范例 06 的四秒推门）。
- 跨镜头保持角色集合、空间几何、屏幕方向、视线、光线、服装和道具状态。

## 交付边界

通用层输出包含：创作意图、镜头结构、素材语义、连续性目标和必要专业术语。下游适配器负责：

- 选择实际模型及版本；未获得用户明确选择时，不从资料来源推断版本。
- 转换素材标签和上传顺序（含官方原形编号 → DSH 顺序编号）。
- 验证时长、分辨率、画幅、素材数量和参数。
- 将时长、比例、分辨率、模型作为结构化参数提交。
