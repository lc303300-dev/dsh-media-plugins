# 视频提示词创意 Brief 契约（统一版 v1.0）

> **唯一真源**：所有视频提示词创意类管线共用本契约 —— 导演线单条、导演线批次、短剧线、Skill 线 V1。
> 各技能只写本线路的**特化**（粒度、区块、模板），不重复定义字段。
> 变更本文件即变更所有线路；改完必须同步安装目录 `~/.dsh/skills/video-director-prompt/references/`。

---

## 一、适用范围

**适用**：任何需要"创意正文"的视频提示词生产——画面内容、逐镜语言、布光调性、故事背景、风格措辞。

**不适用**（不得调用 Gemini 4）：
- 用户明确说"不修改提示词 / 保持原样 / 直接发"→ 只走语义保真规范化；
- 用户已给定完整提示词、且明确要求原样提交；
- 纯标签规范化、编号重排、错别字修正——这些是 Agent 的机械工作。

---

## 二、铁律：谁产什么

| 角色 | 负责 | 不得越界 |
|---|---|---|
| **Agent** | 事实清单、素材文字化、镜头表（镜数/时长/景别/机位）、模板选择、素材绑定与编号、常量块（【风格】【参考】【设定】【特殊要求】【导演】【一致性】【限定】）、验收、提交 | 不手写创意正文；不把"套模板/抄语料原句"当创作 |
| **Gemini 4**（`creative_writer`） | 指定创意区块的正文：画面内容、逐镜语言、布光/背景（按需）、风格措辞（限定字段内） | 不改镜数/时长/景别/机位；不增删镜头；不改编号；不编造事实或台词；不加技术尾巴；不输出解释 |

**一句话判据**：这个区块是否需要"看着真实素材去想象画面"？需要 → Gemini 4；只涉及事实映射/结构/标签 → Agent。

---

## 三、Brief 字段（所有线路同一套）

Brief 是 Agent 写给 Gemini 的任务书；事实材料放 `context`。字段缺失时按"不适用"处理，不得省略 `facts` / `shots` / `output` / `acceptance`。

| 字段 | 必填 | 内容 |
|---|---|---|
| `task` | 是 | `single`（单条提示词）/ `segment`（批次中的一段）/ `batch`（整片多段） |
| `project` | 否 | 片名/项目名/批次号，用于跨段一致性 |
| `purpose` | 否 | 平台与用途（即梦、短片、广告、测试） |
| `materials` | 是 | 每份素材：`图片N` 编号、角色（首帧/场景/三视图/道具/配角/参考视频）、**不要迁移什么**；编号必须按图片→视频→音频的传入顺序。**有参考图时优先把路径放进 `images` 让 Gemini 直读**；无图或图不可用时再由 Agent 文字化（最长边 1920px）。 |
| `facts` | 是 | 角色与换装点、场景实景（材质/家私/光位/色调）、道具状态、人物关系与站位、连续性锚点；**有图时以图为准，文字只补图中看不到的事实** |
| `shots` | 是 | 逐镜：镜号、起-止秒、景别、机位、动作要点（只写"发生什么"，描写交给 Gemini）；镜数/时长是硬约束 |
| `template` | 是 | `T1 镜头N` / `T2 时间轴` / `T3 单一镜头内部时间轴` / `T4 一镜到底` / `T5 视频驱动`，同一层只用一种分段手段 |
| `blocks` | 是 | 本次要 Gemini 写的区块清单（如 `画面内容`、`镜头`、`布光锁定`、`故事背景`） |
| `corpus` | 否 | 语料只给**可迁移结构**摘要（编号/方法/适用条件），**禁止贴原文**；模型版本只作 provenance |
| `constraints` | 是 | 必须成立与绝不出现的事项（文案/事实/安全/平台禁用项） |
| `output` | 是 | 语言、分段格式、每段字数预算、标签形态、时间戳规则 |
| `acceptance` | 是 | 本段验收清单，逐条可机械核对 |

### 3.1 Brief 模板

```text
task: segment
project: <片名/批次>
purpose: 即梦视频提示词

materials:
- 图片1：场景参考；只迁移空间与材质，不迁移人物
- 图片2：角色三视图；只迁移身份与服装，不迁移姿势

facts:
- 角色：<A 服装/换装点>；<B 服装>
- 场景实景：<地面材质；左侧；中间；右侧；后墙；主光源；色调>
- 道具/连续性：<道具状态、人物关系、站位、屏幕方向>

shots:
- 镜1 0.0-2.0s 中景 平视固定：<动作要点>
- 镜2 2.0-5.5s 近景 35mm 缓慢推近：<动作要点>

template: T1
blocks: 画面内容, 镜头
corpus:
- <可迁移结构 1>（来源只作 provenance）
constraints:
- 台词一字不改；不加对白；不写心理活动；不写模型名/分辨率/fps
output:
- 中文；按镜头N分段；每镜一行；全段 500-900 字；只用裸标签 图片N
acceptance:
- 镜数与时长严格一致；时间戳首尾相接；台词逐句原样；无禁用词
```

### 3.2 素材与事实的写法

- **有图就直传 `images`**：图和文字同时给时，图是事实源，文字只补图中看不到的部分（台词、人物关系、不可见约束）；不要先用文字复述一遍再让 Gemini 按文字写。
- 无图或图不可用时才文字化：不要只写"客厅/会所大堂"，要写材质、家私、光位、色调。
- 每份素材写明**不要**从该源迁移什么，避免 Gemini 把参考图整体搬进画面。
- 台词原稿逐句进 `facts` 或 `context`，标明"一字不改"。

## 四、调用参数

```text
creative_writer(
  kind      = prompt        # 视频提示词；剧本/分镜才用 script
  thinking  = base          # 提示词默认 base（快 10-20 倍）；剧本/导演阐述才用 high
  length    = short|medium|long   # 按 output 的字数预算
  brief     = <第三节 Brief>
  context   = <事实材料 + 语料结构摘要；有图时可省略场景描述>
  images    = [<本地图片路径>, ...]  # 可选，≤8 张；有实景/参考图时优先直读
)
```

- **粒度**：单条 = 1 次；批次 = 每段 1 次；短剧整片 = 每 ≤10 段 1 次（manifest 特化）。
- **图片**：`images` 让 Gemini 4 直接读图；每张会做 EXIF 方向归一化，并按**最长边 1920px**（`maxImageEdge` 可配）等比缩放、JPEG q85 后提交，**绝不覆盖原图**。有图时文字描述只补图中看不到的事实；无图时才完全文字化。
- **不重试**：同一次失败不自动重试；改 brief 后再调，最多一次。

---

## 五、输出契约

Gemini 只返回 `blocks` 指定的区块正文：

- 无开场白、无总结、无解释、无 Markdown 标题/加粗/代码块；
- 不写常量块（【风格】【参考】【设定】【特殊要求】【导演】【一致性】【限定】），由 Agent 拼；
- 素材用裸标签 `图片N` / `视频N` / `音频N`，禁用 `@图片N`、`参考图片N`；
- 有镜头表时：镜号/时长/景别/机位按给定值，时间戳从 0 开始首尾相接；
- 台词逐句原样，不润色、不增删；
- 不写模型名、分辨率、帧率、码率、参考模式、API/上传/工具措辞；
- 用户未指定音频时，**由 Agent** 在装配阶段追加 `不生成音乐，仅生成音效。`（不由 Gemini 写）。

---

## 六、Agent 验收清单（硬失败项，逐条核对）

1. 镜数、每镜时长、景别、机位与 `shots` 完全一致；无自加镜/漏镜。
2. 时间戳从 0 开始、首尾相接、末镜等于段时长。
3. 台词逐句原样，顺序不变；无新增对白。
4. 素材标签：`图片N` 绑定正确、不超出该段素材数、同素材同号；无原始文件名/`(2)` 残留。
5. 无心理描写、括号暗示、空泛风格词；无模型名/分辨率/fps/技术尾巴。
6. 同一层只用一种分段手段；模板结构与所选 `template` 一致。
7. 常量块由 Agent 拼，Gemini 输出里不得重复。
8. 事实零编造：人物关系、站位、道具状态、方向与 `facts` 一致。

任何一条硬失败：先判断是"Agent 骨架错"还是"Gemini 创意错"；骨架错改骨架，创意错带修正 brief 重调一次。

## 七、各线路映射

| 线路 | 粒度 | blocks | 调用参数 | 门禁 |
|---|---|---|---|---|
| 导演线·单条 | 1 次/条 | 画面内容 + 镜头（按需布光/背景） | base / medium | `search_corpus`→`authoring_gate`（纪律）→ creative → 校验 → `generate_video` |
| 导演线·批次 | 1 次/段 | 同上 | base / short-medium | 每段 `search_corpus`→`authoring_gate(segment)`→ creative → `set_prompts`（凭证+创作台账+标签门） |
| 短剧线 | 1 次/≤10 段 | 画面内容 + 镜头（+布光/背景） | base / long；剧本/分镜 high | manifest 契约（`drama-tvc-prompt/references/creative-manifest.md`）是其批处理特化 |
| Skill 线 V1 | 1 次/条 | 按业务 Skill 要求 | base / medium | 业务 Skill 知识加载完 → creative → 校验 → `set_prompt` |

**顺序固定**：语料检索 → `authoring_gate`（拿许可，不写正文）→ 组装 brief → `creative_writer` → Agent 验收/装配 → `set_prompts` / `set_prompt` / `generate_video`。
`authoring_gate` 只校验检索凭证，不校验文本质量；创作台账由 `creative_writer` 成功调用写入，`set_prompts` 据此放行。

**图片**：导演单条/批次、Skill 线凡有实景参考图，都把路径放进 `images`（≤8 张，按素材顺序，最长边 1920px 归一化）；短剧整片 manifest 仍以文字资产为主（多场景图容易互相污染），单场精修可传该场图。

## 八、失败处理

| 症状 | 判断 | 动作 |
|---|---|---|
| 镜数/时长/景别错 | Agent 骨架错 | 改 `shots`，重调一次 |
| 台词缺字/改词 | Gemini 自由发挥 | brief 里单独强调台词逐句，重调一次 |
| 标签缺失/编号错 | Agent 装配错 | Agent 规范化，不重调 |
| 编造事实/人物关系 | brief 缺事实 | 补 `facts`，重调一次 |
| 结构跑偏（分段手段混用） | brief 的 `template/output` 不清 | 明确模板与分段，重调一次 |

**兜底规则**：Agent 自写始终是**最终兜底**——`creative_writer` 不可用、或失败一次后，Agent 可以自写；但必须在写入/提交时显式传 `allow_manual_prompts` + `manual_prompts_reason`（批次 `set_prompts`、Skill 线 `set_prompt`、`generate_video` 均如此），结果会留痕。**禁止**连续失败后静默手写。
