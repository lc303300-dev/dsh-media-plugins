# 默认图片生成（统一媒体路由器）

1. **比例必填**：调用 `generate_image` 前，要求用户明确选择 8 个支持比例之一：`21:9`、`16:9`、`3:2`、`4:3`、`1:1`、`3:4`、`2:3`、`9:16`。用户未明确时**停止并询问**；绝不从参考图方向、提示词、历史轮次、文件名或供应商默认推断。通过结构化 `image_ratio` 字段传入。
2. 传非空 `prompt`；图生图时把参考图路径按语义顺序放入 `image` 列表。
3. 不要把 provider、model、API 参数暴露给用户；回退顺序、并发、超时由路由器内部处理。
4. 每次调用都是外部付费操作：生成前确认用户意图；不做投机性生成。
5. 返回结果后直接使用工具返回的路径；不要用原始 Windows 反斜杠路径拼 Markdown 链接。
6. 提交结果不确定（needs_review）时禁止自动重试或换供应商重试，提示用户人工核对后台。
7. 参考图会自动做 EXIF 方向归一化与最长边 1920px 等比缩放后提交，绝不覆盖原图。
