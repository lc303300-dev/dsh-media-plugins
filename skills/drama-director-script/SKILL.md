# 导演脚本（定调 → 节奏 → 九列分镜表 → 任务划分）

> 规则依据：`drama-tvc-prompt/references/shanyin-director-method.md`（五步工作流、六维定调、九列规范）；执行协议：`production-pipeline.md` Step 1–2；三层脚本分工：`video-director-prompt/references/three-script-workflow.md`。

## 输入 / 产出

- 输入：`01-台词定稿.md`（或直接给大纲）
- 产出：`00-导演骨架.md`（定调 / 节奏 / 九列分镜表 / 任务划分 / 12 项自检 / 下一步输入）

## 分工（2026-11-10）

| 内容 | 谁做 |
|---|---|
| 导演定调（六维 + 七项视听决策 + 意象体系）、节奏规划的创意措辞 | **Gemini**（`creative_writer(kind=script, thinking=high)`） |
| 九列分镜表、任务划分、12 项自检 | **Agent 自己**（确定性结构，不调 LLM） |

## 九列分镜表（唯一格式）

```
镜号 | 时长 | 摄影角度 | 景别 | 画面内容 | 场景 | 声音 | 备注 | 叙事目的
```

硬规则：

- 镜号连续，最后一镜时长写「结束」
- 摄影角度只允许：平视 / 俯拍 / 微俯拍 / 仰拍 / 低机位
- 景别只允许：远景 / 全景 / 中远景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- **画面内容只写摄影机拍得到的动作与物体**（不写心理、不写括号暗示）
- 声音列只写：对白（角色：台词）/ 环境声 / 静音
- 叙事目的用客观分析语气，具体到视听手段
- 时长按台词字数算（中文口语约 5 字/秒；台词密集段单镜压到 1–2 秒）
- 一镜一行：硬切/叠化/跳切算新镜号；推拉摇移/焦点转换/角色进出画不算

## 任务划分（草稿，最终在执行脚本定死）

- 单任务 4–15 秒、2–5 镜
- 合段条件：素材共用 / 时空连续 / 叙事单元完整（满足任一且连续）
- **切换场景卡后的第一镜默认特写**（片头建立镜除外）
- 散落短镜（<2 秒）必须与相邻镜合段

## 12 项自检（不通过不进下一步）

镜号连续 / 时长合计 / 景别齐全 / 每镜一个信息 / 画面内容无心理描写 / 声音列合规 / 台词逐句在 / 叙事目的具体 / 任务时长在 4–15 秒 / 每任务 2–5 镜 / 每任务景别数按导演脚本成立 / 场景切换有桥。

细则见 `production-pipeline.md` Step 2。

## 验收

- [ ] 九列表七项硬规则全过
- [ ] 12 项自检全绿
- [ ] 任务划分草稿与台词映射不矛盾（下一层再细化）
- [ ] 定调文字由 Gemini 产出（Agent 不代写）

## 常见返工

| 用户说 | 改法 |
|---|---|
| 太久了 | 减镜，不是压时长 |
| 每个小空间都硬切一遍 | 并镜（合段） |
| 镜头之间像是强行拼接 | 补衔接设计（出点 → 入点 → 手段） |
| 多打角色特写 | 特写三件套：脚步=进新地点 / 手=微观动作 / 眼神=看到了什么（后接看到的物体） |
